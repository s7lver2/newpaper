# newpaper · Subproyecto 4 — Pipeline de IA · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El pipeline que contrasta cada noticia: registro central de proveedores (`config/providers.json`, con Nous Research y NVIDIA NIM, autodetección por prefijo de clave), proxy de claves en Rust (`ai_fetch`, las claves nunca llegan a JS), las 8 etapas con esquemas zod, la posición desde el texto a ciegas (§5.2.1: anonimizado, relativa al grupo de coberturas, léxico + juez LLM con evidencia citada, prueba de espejo, "no determinable"), costes, caché, detector de texto IA, hecho sin cobertura y agente con herramientas visuales, con el idioma de salida como parámetro.

**Architecture:** `packages/pipeline` es TypeScript puro (sin Tauri): recibe sus dependencias por puertos (`Transport` para el `fetch` de los proveedores, `CoverageService`, `LexiconService`, `SourceFetcher`, `CacheStore`, `UsageSink`, `extract`) y se prueba con Vitest y los modelos simulados de `ai/test` (`MockLanguageModelV4`). El crate `np-ai-proxy` valida la URL contra el proveedor, quita cualquier credencial que mande JS, añade la del llavero (`ai.<providerId>`) y devuelve la respuesta en streaming por un `tauri::ipc::Channel`; también guarda la caché de análisis (tabla `analyses`) y el consumo mensual (tabla `usage`). `apps/ui/src/features/ai` monta el pipeline real con esos puertos sobre los comandos Tauri.

**Tech Stack:** `ai` 7.0.133 (`generateText` + `Output.object`, `streamText`, `tool`, `stepCountIs`), `@ai-sdk/openai` 4.0.89, `@ai-sdk/anthropic` 4.0.76, `@ai-sdk/google` 4.0.92, `@ai-sdk/openai-compatible` 3.0.66, `zod` 4.6.5, Vitest 5; Rust `reqwest` 0.13.5 (stream), `futures` 0.3, `base64` 0.23.1, `tauri::ipc::Channel`.

## Decisiones tomadas

1. **Precios dentro de `providers.json`** (cada modelo lleva `price: { input, output }` en USD por millón de tokens, o `null` si se desconoce). `config/prices.json` de la spec (§6.1) se mantiene como **sobrescritura opcional** editable por el usuario (`{"<providerId>/<modelId>": {input, output}}`), que se aplica encima del registro. Así "añadir un proveedor = añadir una entrada" y los precios se actualizan por el manifiesto de contenido (subproyecto 6).
2. **Adaptadores**: `anthropic`, `openai`, `google` con sus paquetes oficiales; el resto (DeepSeek, xAI, Mistral, Perplexity, OpenRouter, Groq, Hugging Face, **Nous Research**, **NVIDIA NIM**, Ollama, LM Studio y endpoints propios) por `@ai-sdk/openai-compatible` contra su API compatible con OpenAI. Menos dependencias y un único camino de pruebas.
3. **Endpoints (verificados con fuentes externas el 2026-10-08; repetir al implementar):** Nous Portal `https://inference-api.nousresearch.com/v1` (modelos `Hermes-4-405B`, `Hermes-4-70B`; clave en `https://portal.nousresearch.com/`; prefijo de clave no documentado → sin autodetección). NVIDIA `https://integrate.api.nvidia.com/v1`, prefijo `nvapi-`, clave en `https://build.nvidia.com/settings/api-keys`.
4. **La clave nunca pasa por JS en el uso**: los adaptadores se crean con `apiKey: "np-proxied"`; Rust borra cualquier cabecera de autenticación que llegue y pone la real. JS solo ve la clave una vez, al pegarla en el asistente (subproyecto 5 → `secret_set`).
5. **Prefijos ambiguos** (`sk-` lo usan OpenAI y DeepSeek): la autodetección devuelve **candidatos** ordenados (gana el prefijo más largo, `sk-ant-` antes que `sk-`); la UI pregunta si hay más de uno.
6. **Temperatura**: varios modelos actuales (Claude 4.6+ y otros) rechazan `temperature`; cada modelo declara `"noTemperature": true` y el pipeline no la envía.
7. **Posición a ciegas**: el juez nunca recibe nombre, dominio ni firma del medio; el texto entra como "Documento A" junto con las coberturas anonimizadas ("Documento B", "C"…). Combinación por defecto `framing = 0,35·léxico + 0,45·juez + 0,10·voces + 0,10·omisiones` (pesos en `config/framing-weights.json`); si la confianza combinada < 0,35 o el intervalo es más ancho que 40 puntos → `framing: null` y `verdict: "no_determinable"`.
8. **Fuentes primarias**: `config/primary-sources.json` (lista blanca por idioma: INE, Eurostat, BOE, Banco de España, AIReF, Maldita, Newtral, Moncloa…). `source_fetch` solo descarga dominios de esa lista o URLs de coberturas que la UI le pasa explícitamente.
9. **Caché**: clave `sha256(url + "\n" + texto)` + etapa; 30 días; tabla `analyses` del subproyecto 1 (fila sincronizable con `id = stable_id("analysis", url|hash|stage)`). El subproyecto 3 lee `stage = "score"` (`$.framing`) y `stage = "verify"` (array de veredictos); este plan los guarda exactamente así.
10. **Límite mensual**: al superarlo, el análisis completo se reasigna a los modelos locales (si no hay ninguno, se queda en el análisis rápido y la UI lo indica).

```rust
#[derive(Debug, thiserror::Error)]
pub enum ProxyError {
    #[error("unknown provider: {0}")]
    UnknownProvider(String),
    #[error("url not allowed for {provider}: {url}")]
    UrlNotAllowed { provider: String, url: String },
    #[error("method not allowed: {0}")]
    MethodNotAllowed(String),
    #[error("request body too large ({0} bytes)")]
    BodyTooLarge(usize),
    #[error("no API key stored for {0}")]
    MissingKey(String),
    #[error("keyring: {0}")]
    Keyring(String),
    #[error("network: {0}")]
    Network(String),
    #[error("cancelled")]
    Cancelled,
    #[error("config: {0}")]
    Config(String),
}

impl ProxyError {
    pub fn code(&self) -> &'static str {
        match self {
            ProxyError::UnknownProvider(_) => "unknown_provider",
            ProxyError::UrlNotAllowed { .. } => "url_not_allowed",
            ProxyError::MethodNotAllowed(_) => "method_not_allowed",
            ProxyError::BodyTooLarge(_) => "body_too_large",
            ProxyError::MissingKey(_) => "missing_key",
            ProxyError::Keyring(_) => "keyring",
            ProxyError::Network(_) => "network",
            ProxyError::Cancelled => "cancelled",
            ProxyError::Config(_) => "config",
        }
    }
}
```

```rust
use std::collections::HashMap;

use serde::{Deserialize, Serialize};
use url::Url;

use crate::ProxyError;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum AuthScheme {
    Bearer,
    XApiKey,
    XGoogApiKey,
    None,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ProviderSpec {
    pub id: String,
    pub base_url: Url,
    pub auth: AuthScheme,
    pub local: bool,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct CustomEndpoint {
    pub id: String,
    pub base_url: String,
    pub auth: AuthScheme,
    pub local: bool,
}

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct RegistryEntry {
    id: String,
    base_url: String,
    auth: AuthScheme,
    #[serde(rename = "type")]
    kind: String,
}

#[derive(Deserialize)]
struct Registry {
    providers: Vec<RegistryEntry>,
}

#[derive(Debug, Clone, Default)]
pub struct ProviderTable {
    specs: HashMap<String, ProviderSpec>,
}

fn with_trailing_slash(mut u: Url) -> Url {
    if !u.path().ends_with('/') {
        let p = format!("{}/", u.path());
        u.set_path(&p);
    }
    u
}

impl ProviderTable {
    pub fn from_registry_json(json: &str) -> Result<Self, ProxyError> {
        let reg: Registry = serde_json::from_str(json).map_err(|e| ProxyError::Config(e.to_string()))?;
        let mut t = ProviderTable::default();
        for p in reg.providers {
            let base = Url::parse(&p.base_url).map_err(|e| ProxyError::Config(format!("{}: {e}", p.id)))?;
            t.specs.insert(p.id.clone(), ProviderSpec { id: p.id, base_url: with_trailing_slash(base), auth: p.auth, local: p.kind == "local" });
        }
        Ok(t)
    }

    /// Solo `custom:*`, `ollama` y `lmstudio` admiten otra URL (los de la nube no se pueden redirigir).
    pub fn upsert_custom(&mut self, ep: &CustomEndpoint) -> Result<(), ProxyError> {
        let overridable = ep.id.starts_with("custom:") || ep.id == "ollama" || ep.id == "lmstudio";
        let deny = || ProxyError::UrlNotAllowed { provider: ep.id.clone(), url: ep.base_url.clone() };
        if !overridable {
            return Err(ProxyError::UnknownProvider(ep.id.clone()));
        }
        let base = with_trailing_slash(Url::parse(&ep.base_url).map_err(|_| deny())?);
        let scheme_ok = base.scheme() == "https" || (base.scheme() == "http" && ep.local);
        if !scheme_ok || !base.username().is_empty() || base.password().is_some() {
            return Err(deny());
        }
        self.specs.insert(ep.id.clone(), ProviderSpec { id: ep.id.clone(), base_url: base, auth: ep.auth, local: ep.local });
        Ok(())
    }

    pub fn get(&self, id: &str) -> Option<&ProviderSpec> {
        self.specs.get(id)
    }

    /// `url` debe colgar de la URL base del proveedor (mismo esquema, host, puerto y prefijo de ruta).
    pub fn authorize(&self, provider_id: &str, url: &str) -> Result<(ProviderSpec, Url), ProxyError> {
        let spec = self.get(provider_id).ok_or_else(|| ProxyError::UnknownProvider(provider_id.to_string()))?;
        let deny = || ProxyError::UrlNotAllowed { provider: provider_id.to_string(), url: url.to_string() };
        if url.contains("/../") || url.contains("/./") {
            return Err(deny());
        }
        let target = Url::parse(url).map_err(|_| deny())?;
        let same_origin = target.scheme() == spec.base_url.scheme()
            && target.host_str() == spec.base_url.host_str()
            && target.port_or_known_default() == spec.base_url.port_or_known_default();
        let no_userinfo = target.username().is_empty() && target.password().is_none();
        let base_path = spec.base_url.path().trim_end_matches('/');
        let in_base = target.path() == base_path || target.path().starts_with(spec.base_url.path());
        if same_origin && no_userinfo && in_base {
            Ok((spec.clone(), target))
        } else {
            Err(deny())
        }
    }
}
```

```rust
use std::{
    collections::HashMap,

use base64::{engine::general_purpose::STANDARD as B64, Engine};
use futures::{
    future::{AbortHandle, Abortable},
    StreamExt,
};
use np_store::secrets::SecretStore;
use serde::{Deserialize, Serialize};

use crate::{
    headers::{auth_header, sanitize_request_headers, sanitize_response_headers},
    table::{AuthScheme, CustomEndpoint, ProviderTable},
    ProxyError,
};

pub const MAX_REQUEST_BODY: usize = 8 * 1024 * 1024;

#[derive(Debug, Clone, Deserialize, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct ProxyRequest {
    pub request_id: String,
    pub url: String,
    pub method: String,
    pub headers: Vec<(String, String)>,
    pub body: Option<String>,
}

/// Orden: `head`, `chunk`*, `end` | `error`.
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase", tag = "event", content = "data")]
pub enum ProxyEvent {
    Head { status: u16, headers: Vec<(String, String)> },
    Chunk { b64: String },
    End,
    Error { code: String, message: String },
}

pub struct AiProxy {
    base: RwLock<ProviderTable>,
    table: RwLock<ProviderTable>,
    secrets: Arc<dyn SecretStore>,
    inflight: Mutex<HashMap<String, AbortHandle>>,
}

/// Nombre de la clave en el llavero: `ai.<proveedor>`; los `custom:x` se guardan como `ai.custom-x`.
pub fn secret_key(provider: &str) -> String {
    format!("ai.{}", provider.replace(':', "-"))
}

impl AiProxy {
    pub fn new(table: ProviderTable, secrets: Arc<dyn SecretStore>) -> Self {
        Self { base: RwLock::new(table.clone()), table: RwLock::new(table), secrets, inflight: Mutex::default() }
    }

    pub fn set_table(&self, table: ProviderTable) {
        *self.base.write().expect("lock") = table.clone();
        *self.table.write().expect("lock") = table;
    }

    pub fn set_custom(&self, endpoints: &[CustomEndpoint]) -> Result<(), ProxyError> {
        let mut t = self.base.read().expect("lock").clone();
        for ep in endpoints {
            t.upsert_custom(ep)?;
        }
        *self.table.write().expect("lock") = t;
        Ok(())
    }

    pub fn cancel(&self, request_id: &str) -> bool {
        self.inflight.lock().expect("lock").remove(request_id).map(|h| h.abort()).is_some()
    }

    pub async fn execute<F>(&self, provider: &str, req: ProxyRequest, client: reqwest::Client, sink: F) -> Result<(), ProxyError>
    where
        F: Fn(ProxyEvent) + Send + Sync,
    {
        let (handle, reg) = AbortHandle::new_pair();
        let id = req.request_id.clone();
        self.inflight.lock().expect("lock").insert(id.clone(), handle);
        let result = match Abortable::new(self.inner(provider, req, client, &sink), reg).await {
            Ok(r) => r,
            Err(_) => Err(ProxyError::Cancelled),
        };
        self.inflight.lock().expect("lock").remove(&id);
        if let Err(e) = &result {
            sink(ProxyEvent::Error { code: e.code().to_string(), message: e.to_string() });
        }
        result
    }

    async fn inner<F>(&self, provider: &str, req: ProxyRequest, client: reqwest::Client, sink: &F) -> Result<(), ProxyError>
    where
        F: Fn(ProxyEvent) + Send + Sync,
    {
        let (spec, url) = self.table.read().expect("lock").authorize(provider, &req.url)?;
        let method = match req.method.to_ascii_uppercase().as_str() {
            "GET" => reqwest::Method::GET,
            "POST" => reqwest::Method::POST,
            other => return Err(ProxyError::MethodNotAllowed(other.to_string())),
        };
        if req.body.as_ref().is_some_and(|b| b.len() > MAX_REQUEST_BODY) {
            return Err(ProxyError::BodyTooLarge(req.body.as_ref().map_or(0, |b| b.len())));
        }
        let mut headers = sanitize_request_headers(&req.headers);
        if spec.auth != AuthScheme::None {
            let key = self
                .secrets
                .get(&secret_key(&spec.id))
                .map_err(|e| ProxyError::Keyring(e.to_string()))?
                .filter(|k| !k.trim().is_empty())
                .ok_or_else(|| ProxyError::MissingKey(spec.id.clone()))?;
            headers.extend(auth_header(spec.auth, key.trim()));
        }
        let mut b = client.request(method, url);
        for (k, v) in &headers {
            b = b.header(k.as_str(), v.as_str());
        }
        if let Some(body) = req.body {
            b = b.body(body);
        }
        let resp = b.send().await.map_err(|e| ProxyError::Network(e.to_string()))?;
        let status = resp.status().as_u16();
        let resp_headers: Vec<(String, String)> = resp.headers().iter().filter_map(|(k, v)| v.to_str().ok().map(|v| (k.as_str().to_string(), v.to_string()))).collect();
        sink(ProxyEvent::Head { status, headers: sanitize_response_headers(&resp_headers) });
        let mut stream = resp.bytes_stream();
        while let Some(chunk) = stream.next().await {
            let bytes = chunk.map_err(|e| ProxyError::Network(e.to_string()))?;
            if !bytes.is_empty() {
                sink(ProxyEvent::Chunk { b64: B64.encode(&bytes) });
            }
        }
        sink(ProxyEvent::End);
        Ok(())
    }
}
```

```rust
        )
    })?;
    Ok(())
}

pub fn month_total(store: &Store, month: &str) -> Result<MonthUsage, StoreError> {
    let by_model: Vec<ModelUsage> = store.with_conn(|c| {
        let mut st = c.prepare("SELECT provider, model, input_tokens, output_tokens, cost, requests FROM usage WHERE month = ?1 ORDER BY cost DESC, provider, model")?;
        let rows = st.query_map([month], |r| Ok(ModelUsage { provider: r.get(0)?, model: r.get(1)?, input_tokens: r.get(2)?, output_tokens: r.get(3)?, cost: r.get(4)?, requests: r.get(5)? }))?;
        rows.collect()
    })?;
    Ok(MonthUsage {
        month: month.to_string(),
        cost: by_model.iter().map(|m| m.cost).sum(),
        input_tokens: by_model.iter().map(|m| m.input_tokens).sum(),
        output_tokens: by_model.iter().map(|m| m.output_tokens).sum(),
        by_model,
    })
}
```

```rust
//! Descarga de fuentes para la verificación: solo lista blanca de fuentes primarias o URLs explícitas.
use crate::ProxyError;

const MAX_SOURCE_BYTES: usize = 4 * 1024 * 1024;

pub fn is_allowed(url: &str, whitelist: &[String], extra: &[String]) -> bool {
    let Ok(u) = url::Url::parse(url) else { return false };
    if !matches!(u.scheme(), "http" | "https") {
        return false;
    }
    if extra.iter().any(|e| e == url) {
        return true;
    }
    let host = u.host_str().unwrap_or("").to_ascii_lowercase();
    whitelist.iter().any(|d| host == *d || host.ends_with(&format!(".{d}")))
}

pub async fn fetch_source(client: &reqwest::Client, url: &str) -> Result<String, ProxyError> {
    let resp = client.get(url).send().await.map_err(|e| ProxyError::Network(e.to_string()))?;
    if !resp.status().is_success() {
        return Err(ProxyError::Network(format!("HTTP {}", resp.status())));
    }
    if resp.content_length().is_some_and(|l| l as usize > MAX_SOURCE_BYTES) {
        return Err(ProxyError::BodyTooLarge(resp.content_length().unwrap_or(0) as usize));
    }
    let text = resp.text().await.map_err(|e| ProxyError::Network(e.to_string()))?;
    if text.len() > MAX_SOURCE_BYTES {
        return Err(ProxyError::BodyTooLarge(text.len()));
    }
    Ok(text)
}
```

```ts
import { RegistryFileSchema, type ModelEntry, type ProviderCategory, type ProviderEntry } from './schema';

export interface Registry {
  providers: ProviderEntry[];
  get(id: string): ProviderEntry | undefined;
  model(providerId: string, modelId: string): ModelEntry | undefined;
  byCategory(cat: ProviderCategory): ProviderEntry[];
  recommended(): ProviderEntry[];
}

export function loadRegistry(json: unknown, priceOverrides: Record<string, { input: number; output: number }> = {}): Registry {
  const file = RegistryFileSchema.parse(json);
  const providers = file.providers.map((p) => ({
    ...p,
    models: p.models.map((m) => ({ ...m, price: priceOverrides[`${p.id}/${m.id}`] ?? m.price })),
  }));
  const get = (id: string) => providers.find((p) => p.id === id);
  return {
    providers,
    get,
    model: (pid, mid) => get(pid)?.models.find((m) => m.id === mid),
    byCategory: (cat) => providers.filter((p) => p.category === cat),
    recommended: () => providers.filter((p) => p.category === 'recommended'),
  };
}
```

```ts
import type { Registry } from './registry';
import type { ProviderEntry } from './schema';

/** Proveedores cuya clave empieza por alguno de sus prefijos; el prefijo más largo gana (§6.1.1). */
export function detectProviders(key: string, registry: Registry): ProviderEntry[] {
  const k = key.trim();
  const hits: { p: ProviderEntry; len: number }[] = [];
  for (const p of registry.providers) {
    const best = Math.max(0, ...p.keyPrefixes.filter((pre) => k.startsWith(pre)).map((pre) => pre.length));
    if (best > 0) hits.push({ p, len: best });
  }
  const top = Math.max(0, ...hits.map((h) => h.len));
  // Solo el prefijo más largo cuenta: "sk-ant-" excluye a OpenAI/DeepSeek ("sk-").
  return hits.filter((h) => h.len === top).map((h) => h.p);
}
```

`packages/pipeline/src/transport/proxyFetch.ts`:
```ts
export interface ProxyRequest { requestId: string; url: string; method: string; headers: [string, string][]; body: string | null }
export type ProxyEvent =
  | { event: 'head'; data: { status: number; headers: [string, string][] } }
  | { event: 'chunk'; data: { b64: string } }
  | { event: 'end' }
  | { event: 'error'; data: { code: string; message: string } };

export interface AiInvoker {
  fetch(provider: string, req: ProxyRequest, onEvent: (e: ProxyEvent) => void): Promise<void>;
  cancel(requestId: string): Promise<boolean>;
}

export class ProxyFetchError extends Error {
  constructor(public code: string, message: string) {
    super(message);
    this.name = 'ProxyFetchError';
  }
}

function decode(b64: string): Uint8Array {
  const bin = atob(b64);
  const out = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i++) out[i] = bin.charCodeAt(i);
  return out;
}

const abortError = () => new DOMException('The operation was aborted.', 'AbortError');

export function makeProxyFetch(provider: string, invoker: AiInvoker): typeof fetch {
  return (async (input: RequestInfo | URL, init?: RequestInit): Promise<Response> => {
    const request = new Request(input, init);
    const body = init?.body !== undefined && init.body !== null ? await request.text() : null;
    const headers: [string, string][] = [];
    request.headers.forEach((v, k) => headers.push([k, v]));
    const req: ProxyRequest = { requestId: crypto.randomUUID(), url: request.url, method: request.method, headers, body };
    const signal = init?.signal ?? null;
    if (signal?.aborted) throw abortError();

    return new Promise<Response>((resolve, reject) => {
      let controller!: ReadableStreamDefaultController<Uint8Array>;
      let started = false;
      let finished = false;
      const stream = new ReadableStream<Uint8Array>({ start: (c) => void (controller = c) });
      const onAbort = () => {
        void invoker.cancel(req.requestId);
        if (!started) reject(abortError());
        else if (!finished) controller.error(abortError());
        finished = true;
      };
      signal?.addEventListener('abort', onAbort, { once: true });
      const onEvent = (e: ProxyEvent) => {
        if (finished) return;
        switch (e.event) {
          case 'head':
            started = true;
            resolve(new Response(stream, { status: e.data.status, headers: e.data.headers }));
            break;
          case 'chunk':
            controller.enqueue(decode(e.data.b64));
            break;
          case 'end':
            finished = true;
            controller.close();
            signal?.removeEventListener('abort', onAbort);
            break;
          case 'error': {
            finished = true;
            const err = new ProxyFetchError(e.data.code, e.data.message);
            if (started) controller.error(err);
            else reject(err);
            signal?.removeEventListener('abort', onAbort);
          }
        }
      };
      invoker.fetch(provider, req, onEvent).catch((err: unknown) => {
        if (!finished) onEvent({ event: 'error', data: { code: 'transport', message: String(err) } });
      });
    });
  }) as typeof fetch;
}
```

```ts
import { generateText, NoObjectGeneratedError, Output, type LanguageModel } from 'ai';
import type { z } from 'zod';

export type StageId = 'claims' | 'quickScore' | 'verify' | 'score' | 'judgeB' | 'synthesis' | 'aiDetect' | 'agent' | 'investigate';

export class StageError extends Error {
  constructor(public stage: StageId, public code: 'invalid_output' | 'provider' | 'aborted', message: string) {
    super(message);
    this.name = 'StageError';
  }
}

export interface Usage { inputTokens: number; outputTokens: number }

export async function generateStructured<T>(opts: {
  model: LanguageModel;
  schema: z.ZodType<T>;
  system: string;
  prompt: string;
  stage: StageId;
  temperature?: number;
  noTemperature?: boolean;
  signal?: AbortSignal;
}): Promise<{ object: T; usage: Usage }> {
  const usage: Usage = { inputTokens: 0, outputTokens: 0 };
  const call = async (prompt: string) => {
    const r = await generateText({
      model: opts.model,
      system: opts.system,
      prompt,
      output: Output.object({ schema: opts.schema }),
      temperature: opts.noTemperature ? undefined : opts.temperature,
      abortSignal: opts.signal,
      maxRetries: 1,
    });
    usage.inputTokens += r.usage.inputTokens ?? 0;
    usage.outputTokens += r.usage.outputTokens ?? 0;
    return r.output as T;
  };
  try {
    return { object: await call(opts.prompt), usage };
  } catch (first) {
    if (opts.signal?.aborted) throw new StageError(opts.stage, 'aborted', 'aborted');
    if (!NoObjectGeneratedError.isInstance(first)) throw new StageError(opts.stage, 'provider', first instanceof Error ? first.message : String(first));
    usage.inputTokens += first.usage?.inputTokens ?? 0;
    usage.outputTokens += first.usage?.outputTokens ?? 0;
    const feedback = `${opts.prompt}\n\nYour previous output was invalid (${String(first.cause ?? first.message).slice(0, 400)}). Previous output:\n${(first.text ?? '').slice(0, 2000)}\nReturn only valid JSON that matches the schema.`;
    try {
      return { object: await call(feedback), usage };
    } catch (second) {
      throw new StageError(opts.stage, NoObjectGeneratedError.isInstance(second) ? 'invalid_output' : 'provider', second instanceof Error ? second.message : String(second));
    }
  }
}
```

```ts
import type { StageId } from '../llm/structured';
import type { Registry } from '../registry/registry';
import type { ModelEntry, ProviderEntry } from '../registry/schema';

export interface Assignment { provider: string; model: string; temperature?: number; fallback?: { provider: string; model: string } }
export type Assignments = Partial<Record<StageId, Assignment>>;
export type PresetId = 'privacy' | 'balanced' | 'quality' | 'cheap';
export const PRESETS: { id: PresetId }[] = [{ id: 'privacy' }, { id: 'balanced' }, { id: 'quality' }, { id: 'cheap' }];

const LIGHT: StageId[] = ['claims', 'quickScore', 'aiDetect'];
const HEAVY: StageId[] = ['verify', 'score', 'synthesis', 'agent', 'investigate'];
const TEMPERATURE: Partial<Record<StageId, number>> = { claims: 0, quickScore: 0, verify: 0, score: 0, judgeB: 0, aiDetect: 0, synthesis: 0.3, agent: 0.4, investigate: 0.2 };

interface Candidate { p: ProviderEntry; m: ModelEntry }

function candidates(reg: Registry, connected: string[], localModels: Record<string, string[]>): Candidate[] {
  const out: Candidate[] = [];
  for (const p of reg.providers) {
    if (!connected.includes(p.id)) continue;
    if (p.type === 'local') {
      const ids = localModels[p.id]?.length ? localModels[p.id]! : p.models.map((m) => m.id);
      for (const id of ids) out.push({ p, m: p.models.find((m) => m.id === id) ?? { id, name: id, price: { input: 0, output: 0 }, latency: 'medium', capabilities: ['structured'], tier: 'light' } });
    } else {
      for (const m of p.models) if (m.capabilities.includes('structured')) out.push({ p, m });
    }
  }
  return out;
}

const cost = (c: Candidate) => (c.m.price ? c.m.price.input + c.m.price.output * 3 : Number.POSITIVE_INFINITY);
const rank = (c: Candidate) => (c.p.category === 'recommended' ? 0 : 1);

function pick(list: Candidate[], want: { local?: boolean; tier?: 'light' | 'strong'; cheapest?: boolean; exclude?: string }): Candidate | undefined {
  let l = list.filter((c) => (want.local === undefined ? true : (c.p.type === 'local') === want.local) && c.p.id !== want.exclude);
  if (want.tier) {
    const tiered = l.filter((c) => c.m.tier === want.tier);
    if (tiered.length) l = tiered;
  }
  const sorted = [...l].sort((a, b) => (want.cheapest ? cost(a) - cost(b) : rank(a) - rank(b) || Number(b.m.tier === 'strong') - Number(a.m.tier === 'strong')));
  return sorted[0];
}

export function autoAssign(reg: Registry, connected: string[], preset: PresetId, localModels: Record<string, string[]> = {}): Assignments {
  const list = candidates(reg, connected, localModels);
  if (!list.length) return {};
  const local = pick(list, { local: true });
  const fallback = local ? { provider: local.p.id, model: local.m.id } : undefined;
  const as = (c: Candidate | undefined, stage: StageId): Assignment | undefined =>
    c ? { provider: c.p.id, model: c.m.id, temperature: TEMPERATURE[stage], ...(fallback && c.p.type !== 'local' ? { fallback } : {}) } : undefined;

  const out: Assignments = {};
  const set = (stage: StageId, c: Candidate | undefined) => {
    const a = as(c, stage);
    if (a) out[stage] = a;
  };

  if (preset === 'privacy') {
    for (const s of [...LIGHT, ...HEAVY]) set(s, local);
    return out;
  }
  const strong = pick(list, { local: false, tier: 'strong' }) ?? local;
  const cheapCloud = pick(list, { local: false, tier: 'light', cheapest: true }) ?? strong;
  for (const s of LIGHT) {
    if (preset === 'quality') set(s, strong);
    else if (preset === 'cheap') set(s, pick(list, { cheapest: true, tier: 'light' }));
    else set(s, local ?? cheapCloud);
  }
  for (const s of HEAVY) set(s, preset === 'cheap' ? cheapCloud : strong);
  if (local) set('quickScore', local);
  if (preset === 'balanced' || preset === 'quality') {
    const other = pick(list, { local: false, tier: 'strong', exclude: strong?.p.id });
    if (other && other.p.id !== strong?.p.id) set('judgeB', other);
  }
  return out;
}

export function describeAssignment(reg: Registry, a: Assignments) {
  return (Object.entries(a) as [StageId, Assignment][]).map(([stage, x]) => {
    const p = reg.get(x.provider);
    return { stage, providerName: p?.name ?? x.provider, modelName: reg.model(x.provider, x.model)?.name ?? x.model, local: p?.type === 'local' };
  });
}
```

```ts
/** §6.2/§10: si el modelo asignado falla, se usa su fallback (por defecto, el local). */
export async function runWithFallback<T>(primary: () => Promise<T>, fallback?: () => Promise<T>): Promise<{ value: T; usedFallback: boolean }> {
  try {
    return { value: await primary(), usedFallback: false };
  } catch (e) {
    if (!fallback) throw e;
    return { value: await fallback(), usedFallback: true };
  }
}
```

```ts
import type { StageId, Usage } from '../llm/structured';
import type { Registry } from '../registry/registry';

export const estimateTokens = (text: string) => Math.ceil(text.length / 4);

/** Salida típica por etapa (tokens), para la estimación previa (§6.2 "Coste: estimado por etapa"). */
export const STAGE_OUTPUT_TOKENS: Record<StageId, number> = {
  claims: 1200, quickScore: 400, verify: 2500, score: 1500, judgeB: 1500, synthesis: 3000, aiDetect: 600, agent: 1200, investigate: 2000,
};
const PROMPT_OVERHEAD = 900;

export function stageInputTokens(stage: StageId, articleChars: number, coverageCount: number): number {
  const article = Math.ceil(articleChars / 4);
  switch (stage) {
    case 'verify': return PROMPT_OVERHEAD + article + coverageCount * 1500;
    case 'score':
    case 'judgeB': return PROMPT_OVERHEAD + article * (1 + Math.min(coverageCount, 5));
    case 'synthesis': return PROMPT_OVERHEAD + article + coverageCount * 800 + 2500;
    default: return PROMPT_OVERHEAD + article;
  }
}

export function costOf(model: ModelEntry | undefined, inputTokens: number, outputTokens: number): number | null {
  if (!model?.price) return null;
  return (inputTokens * model.price.input + outputTokens * model.price.output) / 1_000_000;
}

export function estimateAnalysis(reg: Registry, a: Assignments, articleText: string, coverageCount: number) {
  const perStage = (Object.entries(a) as [StageId, NonNullable<Assignments[StageId]>][]).map(([stage, x]) => ({
    stage,
    usd: costOf(reg.model(x.provider, x.model), stageInputTokens(stage, articleText.length, coverageCount), STAGE_OUTPUT_TOKENS[stage]),
  }));
  return { perStage, totalUsd: perStage.reduce((n, s) => n + (s.usd ?? 0), 0), unknown: perStage.some((s) => s.usd === null) };
}

export interface UsageSink {
  record(provider: string, model: string, usage: Usage, costUsd: number): Promise<void>;
}
```

```ts
import type { Registry } from '../registry/registry';

/** §6.2: "límite mensual: al alcanzarlo, el análisis completo pasa a modelos locales". */
export function applyBudget(a: Assignments, spentUsd: number, limitUsd: number | null, reg: Registry): { assignments: Assignments; capped: boolean } {
  if (limitUsd === null || spentUsd < limitUsd) return { assignments: a, capped: false };
  const out: Assignments = {};
  for (const [stage, x] of Object.entries(a) as [StageId, Assignment][]) {
    if (reg.get(x.provider)?.type === 'local') out[stage] = x;
    else if (x.fallback) out[stage] = { provider: x.fallback.provider, model: x.fallback.model };
  }
  return { assignments: out, capped: true };
}
```

```ts
export interface CacheStore {
  get(url: string, hash: string, stage: string): Promise<string | null>;
  put(url: string, hash: string, stage: string, json: string, model: string | null, costUsd: number): Promise<void>;
}

export async function textHash(url: string, text: string): Promise<string> {
  const bytes = new TextEncoder().encode(`${url}\n${text}`);
  const digest = await crypto.subtle.digest('SHA-256', bytes);
  return Array.from(new Uint8Array(digest), (b) => b.toString(16).padStart(2, '0')).join('');
}

/** §6.2 "Caché: resultados por hash(url + texto) 30 días; reutilización entre pestañas". */
export async function cachedStage<T>(
  cache: CacheStore,
  url: string,
  hash: string,
  stage: string,
  compute: () => Promise<{ value: T; model: string | null; costUsd: number }>,
): Promise<{ value: T; fromCache: boolean }> {
  const hit = await cache.get(url, hash, stage);
  if (hit !== null) return { value: JSON.parse(hit) as T, fromCache: true };
  const r = await compute();
  await cache.put(url, hash, stage, JSON.stringify(r.value), r.model, r.costUsd);
  return { value: r.value, fromCache: false };
}
```

```ts
import { languageInstruction } from '../llm/language';

import type { ArticleInput } from '../schemas/article';

import type { StageCtx, StageResult } from './ctx';

export function repairSpans<T extends { quote: string; span: [number, number] }>(text: string, items: T[]): T[] {
  const out: T[] = [];
  for (const it of items) {
    if (text.slice(it.span[0], it.span[1]) === it.quote) {
      out.push(it);
      continue;
    }
    let best = -1;
    for (let i = text.indexOf(it.quote); i >= 0; i = text.indexOf(it.quote, i + 1)) {
      if (best < 0 || Math.abs(i - it.span[0]) < Math.abs(best - it.span[0])) best = i;
    }
    if (best >= 0) out.push({ ...it, span: [best, best + it.quote.length] });
  }
  return out;
}

const SYSTEM = (quick: boolean) => `You analyse news articles for a fact-checking tool.
${quick ? 'Return only loaded phrases: set "claims" to an empty array.' : `List the article's claims. kind: "hecho" (verifiable fact), "cifra" (number or statistic), "opinion" (value judgement or intention), "atribucion" (something attributed to a named source). checkable=true only if public evidence could confirm or refute it.`}
List loaded phrases: emotionally charged, hyperbolic or evaluative wording; give the reason in one short sentence.
Every "quote" must be copied verbatim from the article (exact characters) and "span" must be its [start, end) character offsets.`;

export async function detectClaims(ctx: StageCtx, article: ArticleInput, opts: { quick: boolean }): Promise<StageResult<ClaimsOutput>> {
  const r = await generateStructured({
    model: ctx.model,
    schema: ClaimsOutputSchema,
    system: `${SYSTEM(opts.quick)}\n${UNTRUSTED_NOTE}\n${languageInstruction(ctx.locale)}`,
    prompt: `${opts.quick ? 'Only loaded phrases.' : 'Claims and loaded phrases.'}\n${delimit('ARTICLE', article.text)}`,
    stage: opts.quick ? 'quickScore' : 'claims',
    temperature: ctx.temperature,
    noTemperature: ctx.noTemperature,
    signal: ctx.signal,
  });
  const claims = repairSpans(article.text, r.object.claims).map((c, i) => ({ ...c, id: `c${i + 1}` }));
  const loadedPhrases = repairSpans(article.text, r.object.loadedPhrases);
  return { value: { claims: opts.quick ? [] : claims, loadedPhrases }, usage: r.usage };
}
```

```ts
import type { OutputLocale } from '../llm/language';

const esc = (s: string) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');

const SELF_REFS: Record<OutputLocale, RegExp[]> = {
  es: [
    /\b(seg[uú]n|como) (public[oó]|inform[oó]|adelant[oó]|revel[oó]) [^,.;]*[,.;]?\s*/gi,
    /,?\s*(consultad[ao]s? por|a las que ha tenido acceso|seg[uú]n ha sabido) (este|esta) (diario|peri[oó]dico|medio|cabecera|redacci[oó]n)/gi,
    /\b(este|esta|nuestro|nuestra) (diario|peri[oó]dico|medio|cabecera|redacci[oó]n)\b/gi,
  ],
  en: [/\b(as|according to what) (this|our) (newspaper|paper|outlet|site) (reported|revealed)[^,.;]*[,.;]?\s*/gi, /\b(this|our) (newspaper|paper|outlet|newsroom)\b/gi],
  de: [/\bwie (unsere|diese) (Zeitung|Redaktion) (berichtete|meldete|erfuhr)[^,.;]*[,.;]?\s*/gi, /\b(unsere|diese) (Zeitung|Redaktion)\b/gi],
};

const CAPTIONS = /^(foto|imagen|fotograf[ií]a|photo|picture|bild|image)\s*:.*$/gim;
const BYLINE_LEAD = /^\s*(por|by|von)\s+[^.\n]{2,80}\.\s*/i;

export function anonymize(text: string, info: { outletNames: string[]; domains: string[]; bylines: string[]; locale: OutputLocale }): string {
  let t = text.replace(CAPTIONS, '');
  for (const b of info.bylines.filter(Boolean)) {
    t = t.replace(new RegExp(`^\\s*(por|by|von)\\s+${esc(b)}\\.?\\s*`, 'i'), '').replace(new RegExp(esc(b), 'gi'), '');
  }
  t = t.replace(BYLINE_LEAD, (m) => (info.bylines.length ? '' : m));
  t = t.replace(/https?:\/\/\S+/g, '');
  for (const d of info.domains.filter(Boolean)) t = t.replace(new RegExp(`(www\\.)?${esc(d)}\\S*`, 'gi'), '');
  for (const re of SELF_REFS[info.locale]) t = t.replace(re, '');
  for (const n of info.outletNames.filter((x) => x.trim().length > 2)) t = t.replace(new RegExp(esc(n), 'gi'), '');
  return t
    .split('\n')
    .map((l) => l.replace(/\s{2,}/g, ' ').replace(/\s+([,.;])/g, '$1').replace(/(^|[.!?]\s+)[,;]\s*/g, '$1').trim())
    .filter((l) => l && !/^[\s/.,;:–-]*$/.test(l))
    .join('\n');
}

const LETTERS = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ';
export function docLabel(i: number, locale: OutputLocale): string {
  return `${locale === 'es' ? 'Documento' : 'Document'} ${LETTERS[i % 26]}`;
}
```

```ts
import type { Score, Signal, SignalKind } from '../schemas/score';

export type Side = 'left' | 'center' | 'right';
export interface JudgeOutput {
  signals: { kind: SignalKind; value: number; evidence: string[] }[];
  actors: { name: string; quotes: number; side: Side }[];
  lastWordSide: Side | null;
  omissions: { fact: string; favors: 'left' | 'right' | 'none'; foundIn: string }[];
}
export interface FramingWeights { lexicon: number; judge: number; voices: number; omissions: number; minConfidence?: number; maxIntervalWidth?: number }
export const DEFAULT_WEIGHTS: FramingWeights = { lexicon: 0.35, judge: 0.45, voices: 0.1, omissions: 0.1, minConfidence: 0.35, maxIntervalWidth: 40 };

const norm = (s: string) => s.toLowerCase().replace(/\s+/g, ' ').trim();
const clamp = (x: number, a: number, b: number) => Math.min(b, Math.max(a, x));
const mean = (xs: number[]) => (xs.length ? xs.reduce((a, b) => a + b, 0) / xs.length : 0);

/** §5.2.1.5: sin cita literal, la señal no cuenta. Las omisiones deben estar en otro documento. */
export function validateEvidence(out: JudgeOutput, docA: string, others: Map<string, string>): JudgeOutput {
  const a = norm(docA);
  return {
    ...out,
    signals: out.signals
      .map((s) => ({ ...s, evidence: s.evidence.filter((e) => e.trim().length >= 3 && a.includes(norm(e))) }))
      .filter((s) => s.evidence.length > 0),
    omissions: out.omissions.filter((o) => {
      const doc = others.get(o.foundIn);
      return !!doc && norm(doc).includes(norm(o.fact).slice(0, 40));
    }),
  };
}

export function combineFraming(o: {
  judge: JudgeOutput | null;
  lexiconRel: { value: number; confidence: number; evidence: string[] } | null;
  groupCenter: number;
  loadedPhrases: number;
  weights: FramingWeights;
}): Score {
  const signals: Signal[] = [];
  const parts: { w: number; v: number; conf: number }[] = [];
  const j = o.judge;

  if (o.lexiconRel) {
    signals.push({ kind: 'lexico', value: clamp(o.lexiconRel.value, -1, 1), evidence: o.lexiconRel.evidence, source: 'lexicon' });
    parts.push({ w: o.weights.lexicon, v: o.lexiconRel.value, conf: o.lexiconRel.confidence });
  }
  if (j?.signals.length) {
    for (const s of j.signals) signals.push({ ...s, value: clamp(s.value, -1, 1), source: 'judge' });
    const ev = j.signals.reduce((n, s) => n + s.evidence.length, 0);
    parts.push({ w: o.weights.judge, v: mean(j.signals.map((s) => s.value)), conf: Math.min(1, ev / 6) });
  }
  const sideVal = (s: Side) => (s === 'left' ? -1 : s === 'right' ? 1 : 0);
  const totalQuotes = j?.actors.reduce((n, a) => n + a.quotes, 0) ?? 0;
  if (j && totalQuotes > 0) {
    const v = clamp(j.actors.reduce((n, a) => n + sideVal(a.side) * a.quotes, 0) / totalQuotes + (j.lastWordSide ? sideVal(j.lastWordSide) * 0.25 : 0), -1, 1);
    signals.push({ kind: 'voces', value: v, evidence: j.actors.filter((a) => a.quotes > 0).map((a) => `${a.name} (${a.quotes})`), source: 'computed' });
    parts.push({ w: o.weights.voices, v, conf: Math.min(1, totalQuotes / 4) });
  }
  if (j?.omissions.length) {
    // Omitir datos que favorecen a la izquierda empuja el texto a la derecha, y viceversa.
    const v = clamp(j.omissions.reduce((n, x) => n + (x.favors === 'left' ? 1 : x.favors === 'right' ? -1 : 0), 0) / j.omissions.length, -1, 1);
    signals.push({ kind: 'omision', value: v, evidence: j.omissions.map((x) => x.fact), source: 'computed' });
    parts.push({ w: o.weights.omissions, v, conf: Math.min(1, j.omissions.length / 3) });
  }

  const voices = { actors: (j?.actors ?? []).map((a) => ({ name: a.name, quotes: a.quotes })), lastWord: j?.actors.find((a) => j.lastWordSide && a.side === j.lastWordSide)?.name ?? null };
  const omissions = (j?.omissions ?? []).map((x) => x.fact);
  const totalW = parts.reduce((n, p) => n + p.w, 0);
  const rel = totalW ? parts.reduce((n, p) => n + p.w * p.v, 0) / totalW : 0;
  const spread = parts.length > 1 ? Math.sqrt(mean(parts.map((p) => (p.v - rel) ** 2))) : 0.5;
  const coverage = totalW / (o.weights.lexicon + o.weights.judge + o.weights.voices + o.weights.omissions);
  const evidence = totalW ? parts.reduce((n, p) => n + p.w * p.conf, 0) / totalW : 0;
  const confidence = clamp(0.45 * coverage + 0.35 * evidence + 0.2 * (1 - Math.min(1, spread)), 0, 1);
  const half = 8 + 40 * (1 - confidence) + 20 * Math.min(1, spread);
  const meanAbs = mean(signals.map((s) => Math.abs(s.value)));
  const neutrality = Math.round(clamp(100 - 60 * meanAbs - 4 * o.loadedPhrases, 0, 100));

  const notDeterminable = parts.length < 2 || confidence < (o.weights.minConfidence ?? 0.35) || half * 2 > (o.weights.maxIntervalWidth ?? 40);
  if (notDeterminable) return { neutrality, framing: null, confidence, interval: null, signals, voices, omissions, verdict: 'no_determinable' };

  const framing = Math.round(clamp(o.groupCenter + 50 * rel, 0, 100));
  const verdict = neutrality >= 75 ? 'neutral' : neutrality >= 55 ? 'sesgo_leve' : neutrality >= 35 ? 'sesgado' : 'muy_sesgado';
  return { neutrality, framing, confidence, interval: [Math.max(0, Math.round(framing - half)), Math.min(100, Math.round(framing + half))], signals, voices, omissions, verdict };
}
```

> Con las señales del primer test (léxico −0,5, juez −0,65 de media, voces −1, omisión −1) la posición queda en torno a 50 − 50·0,65 ≈ 18 y la neutralidad baja por la carga adjetiva: el test solo exige < 40 y < 70.
> En el test "contradictorio" el léxico dice −0,9 y el juez +0,9: la dispersión es máxima (0,9) y el intervalo supera 40 puntos → `no_determinable`.

```ts
Signals and anchors:
- lexico (word choice used disproportionately by one bloc): -1 "patronal" vs +1 "empresarios"; -1 "personas que ocupan" vs +1 "okupas".
- encuadre (economic, moral, conflict, security, rights frame): -1 a wage rise as "social justice" vs +1 as "a threat to jobs".
- atribucion (verbs that judge the speaker): "denuncia", "alerta", "reconoce" vs neutral "dice", "afirma". Sign by whom it favours.
- adjetivacion (evaluative adjectives, hyperbole): "apocalipsis de empleo", "fiel a su costumbre".

For each signal you MUST quote the exact fragments of Documento A / Document A that justify it in "evidence"; a signal without a verbatim quote does not count.
List the actors quoted in Document A with the number of quotes and the side they speak for, and which side has the last word.

    model: o.ctx.model,
    schema: JudgeSchema,

    stage: 'score',
    temperature: o.ctx.temperature ?? 0,
    noTemperature: o.ctx.noTemperature,
    signal: o.ctx.signal,
  });
```

```ts
import type { LexiconService } from '../run/ports';
import type { ArticleInput } from '../schemas/article';
import type { Coverage } from '../schemas/coverage';
import type { Score } from '../schemas/score';
import { anonymize, docLabel } from './anonymize';
import { addUsage, ZERO_USAGE, type StageCtx, type StageResult } from './ctx';
import { combineFraming, validateEvidence, type FramingWeights, type JudgeOutput } from './framing';
import { judgeDocument } from './judge';

const mean = (xs: number[]) => xs.reduce((a, b) => a + b, 0) / xs.length;

async function lexiconRelative(lexicon: LexiconService, locale: StageCtx['locale'], text: string, others: string[]) {
  const a = await lexicon.score(text, locale);
  if (a.status !== 'ok' || a.value === null) return null;
  const group = (await Promise.all(others.map((t) => lexicon.score(t, locale)))).filter((s) => s.status === 'ok' && s.value !== null).map((s) => s.value!);
  const center = group.length ? mean(group) : 50;
  return { value: Math.max(-1, Math.min(1, (a.value - center) / 50)), confidence: a.confidence, evidence: a.matches.slice(0, 8).map((m) => text.slice(m.start, m.end)) };
}

export async function scoreArticle(o: {
  ctx: StageCtx;
  ctxB?: StageCtx & { label: string };
  article: ArticleInput;
  coverages: Coverage[];
  coverageTexts: Map<string, string>;
  outletNames: string[];
  domains: string[];
  lexicon: LexiconService;
  loadedPhrases: number;
  weights: FramingWeights;
}): Promise<StageResult<Score>> {
  const anon = (t: string) => anonymize(t, { outletNames: o.outletNames, domains: o.domains, bylines: [o.article.byline ?? ''].filter(Boolean), locale: o.ctx.locale });
  const docA = anon(o.article.text);
  const others = o.coverages
    .slice(0, 5)
    .map((c, i) => ({ label: docLabel(i + 1, o.ctx.locale), text: anon(o.coverageTexts.get(c.url) ?? c.title) }));
  const othersMap = new Map(others.map((d) => [d.label, d.text]));
  const known = o.coverages.map((c) => c.lean).filter((l): l is number => l !== null);
  const groupCenter = known.length ? mean(known) : 50;

  const lexiconRel = await lexiconRelative(o.lexicon, o.ctx.locale, o.article.text, o.coverages.map((c) => o.coverageTexts.get(c.url) ?? c.title));
  const runJudge = async (ctx: StageCtx) => {
    const r = await judgeDocument({ ctx, docA, others, mode: others.length ? 'relative' : 'absolute' });
    return { judge: validateEvidence(r.value, docA, othersMap), usage: r.usage };
  };
  const a = await runJudge(o.ctx);
  const score = combineFraming({ judge: a.judge, lexiconRel, groupCenter, loadedPhrases: o.loadedPhrases, weights: o.weights });
  let usage = addUsage(ZERO_USAGE, a.usage);
  if (o.ctxB) {
    const b = await runJudge(o.ctxB).catch(() => null);
    if (b) {
      usage = addUsage(usage, b.usage);
      const sb = combineFraming({ judge: b.judge, lexiconRel, groupCenter, loadedPhrases: o.loadedPhrases, weights: o.weights });
      score.judges = [{ model: 'A', framing: score.framing }, { model: o.ctxB.label, framing: sb.framing }];
      score.crossModelDisagreement = score.framing !== null && sb.framing !== null && Math.abs(score.framing - sb.framing) > 20;
    }
  }
  return { value: score, usage };
}

/** Análisis rápido (§6.2): etapa 5 parcial con un modelo local, sin coberturas. */
export async function quickScore(o: { ctx: StageCtx; article: ArticleInput; lexicon: LexiconService; loadedPhrases: number }): Promise<StageResult<Score>> {
  const docA = anonymize(o.article.text, { outletNames: [o.article.siteName ?? ''].filter(Boolean), domains: [], bylines: [o.article.byline ?? ''].filter(Boolean), locale: o.ctx.locale });
  const r = await judgeDocument({ ctx: o.ctx, docA, others: [], mode: 'absolute' });
  const lex = await o.lexicon.score(o.article.text, o.ctx.locale);
  const lexiconRel = lex.status === 'ok' && lex.value !== null ? { value: (lex.value - 50) / 50, confidence: lex.confidence, evidence: lex.matches.slice(0, 8).map((m) => o.article.text.slice(m.start, m.end)) } : null;
  const judge: JudgeOutput = validateEvidence(r.value, docA, new Map());
  const s = combineFraming({ judge, lexiconRel, groupCenter: 50, loadedPhrases: o.loadedPhrases, weights: { lexicon: 0.4, judge: 0.6, voices: 0.1, omissions: 0, minConfidence: 0.1, maxIntervalWidth: 100 } });
  return { value: { ...s, confidence: Math.min(0.4, s.confidence) }, usage: r.usage };
}
```

```ts
/** §5.2.1.7 Prueba de espejo: intercambiar actores y términos de un bloque por los del otro. */
export function mirrorText(text: string, swaps: [string, string][]): string {
  let t = text;
  swaps.forEach(([a, b], i) => {
    t = t.replace(new RegExp(`\\b${a}\\b`, 'g'), `\u0000${i}A\u0000`).replace(new RegExp(`\\b${b}\\b`, 'g'), `\u0000${i}B\u0000`);
  });
  swaps.forEach(([a, b], i) => {
    t = t.replaceAll(`\u0000${i}A\u0000`, b).replaceAll(`\u0000${i}B\u0000`, a);
  });
  return t;
}

export async function mirrorCheck(score: (t: string) => Promise<number | null>, text: string, swaps: [string, string][], tolerance = 8) {
  const a = await score(text);
  const b = await score(mirrorText(text, swaps));
  const symmetric = a !== null && b !== null && Math.abs(a - 50 + (b - 50)) <= tolerance;
  return { a, b, symmetric };
}

/** Error medio absoluto por bloque en un conjunto ciego etiquetado por personas; `bias` = diferencia entre bloques. */
export async function blocError(items: { text: string; humanFraming: number; bloc: 'left' | 'right' }[], score: (t: string) => Promise<number | null>) {
  const err = { left: [] as number[], right: [] as number[] };
  for (const it of items) {
    const s = await score(it.text);
    if (s !== null) err[it.bloc].push(Math.abs(s - it.humanFraming));
  }
  const m = (xs: number[]) => (xs.length ? xs.reduce((a, b) => a + b, 0) / xs.length : 0);
  const left = m(err.left);
  const right = m(err.right);
  return { left, right, bias: Math.abs(left - right) };
}
```

```ts
import { languageInstruction } from '../llm/language';
import { generateStructured } from '../llm/structured';
import type { ArticleInput } from '../schemas/article';

import type { Coverage } from '../schemas/coverage';
import type { Score } from '../schemas/score';
import { SynthesisSchema, type Synthesis } from '../schemas/synthesis';
import type { Verdict } from '../schemas/verdicts';
import type { Visualization } from '../schemas/visualization';
import type { StageCtx, StageResult } from './ctx';
import type { RetrievedSource } from './verify';

export function validateVisualizations(vs: Visualization[], sourceIds: Set<string>, partyIds: Set<string>): Visualization[] {
  const out: Visualization[] = [];
  for (const v of vs) {
    const ids = v.sourceIds.filter((id) => sourceIds.has(id));
    if (!ids.length) continue; // §6.2: datos sin fuente → no se dibujan
    if (v.type === 'parliament') {
      const { total, majority, series } = v.data;
      if (majority !== Math.floor(total / 2) + 1) continue;
      if (series.some((s) => s.seats.reduce((n, x) => n + x.seats, 0) > total)) continue;
      if (series.some((s) => s.seats.some((x) => !partyIds.has(x.partyId)))) continue;
    }
    out.push({ ...v, sourceIds: ids } as Visualization);
  }
  return out;
}

const SYSTEM = `Write a neutral version of the news event, based only on the article, the verdicts and the retrieved sources.
- headline: neutral, factual. summary3: exactly three sentences.
- facts: each with kind hecho (established), atribuida (attributed to someone) or disputa (contested), and the ids (S1…) of the sources that support it.
- parties: what each side says, with the source id.
- disputes: contested questions with positions and how much evidence supports each (0–1).
- unknowns: what is not known yet.
- visualizations: only when data comes from the cited sources; types bar, line, range, stacked, matrix, table, parliament (seats per party id from the parliament list given), map. Never invent numbers.
- rewrites: for loaded or misleading wording, {from: exact fragment of the original article, to: neutral wording, reason}.`;

  ctx: StageCtx;
  article: ArticleInput;
  claims: Claim[];
  verdicts: Verdict[];
  sources: RetrievedSource[];
  coverages: Coverage[];
  score: Score | null;
  partyIds: Set<string>;
}): Promise<StageResult<Synthesis>> {
  const r = await generateStructured({
    model: o.ctx.model,
    schema: SynthesisSchema,
    system: `${SYSTEM}\nParliament party ids: ${[...o.partyIds].join(', ') || 'none'}.\n${UNTRUSTED_NOTE}\n${languageInstruction(o.ctx.locale)}`,
    prompt: [
      delimit('ARTICLE', o.article.text),
      `Claims and verdicts:\n${o.claims.map((c) => `${c.id}: ${c.quote} → ${o.verdicts.find((v) => v.claimId === c.id)?.status ?? 'sin verificar'}`).join('\n')}`,
      `Other coverage headlines: ${o.coverages.map((c) => c.title).join(' | ')}`,
      ...o.sources.map((s) => delimit(`SOURCE ${s.id}`, `${s.title}\n${s.text}`)),
    ].join('\n'),
    stage: 'synthesis',
    temperature: o.ctx.temperature,
    noTemperature: o.ctx.noTemperature,
    signal: o.ctx.signal,
  });
  const ids = new Set(o.sources.map((s) => s.id));
  const s = r.object;
  return {
    value: {
      ...s,
      facts: s.facts.map((f) => ({ ...f, sourceIds: f.sourceIds.filter((id) => ids.has(id)) })),
      parties: s.parties.filter((p) => ids.has(p.sourceId)),
      visualizations: validateVisualizations(s.visualizations, ids, o.partyIds),
      rewrites: s.rewrites.filter((w) => o.article.text.includes(w.from)),
```

```ts
import { z } from 'zod';
import { delimit, UNTRUSTED_NOTE } from '../llm/delimit';
import type { OutputLocale } from '../llm/language';
import { generateStructured } from '../llm/structured';
import type { AiAuthorship } from '../schemas/authorship';
import { ZERO_USAGE, type StageCtx, type StageResult } from './ctx';

export const TEMPLATE_PHRASES: Record<OutputLocale, string[]> = {
  es: ['es importante destacar', 'es importante señalar', 'es importante subrayar', 'cabe señalar', 'cabe destacar', 'en conclusión', 'en definitiva', 'en resumen', 'sin lugar a dudas', 'en el panorama actual', 'juega un papel crucial'],
  en: ['it is important to note', 'it is worth noting', 'in conclusion', 'in summary', 'plays a crucial role', 'in today\'s landscape', 'delve into', 'a testament to'],
  de: ['es ist wichtig zu beachten', 'zusammenfassend', 'abschließend lässt sich sagen', 'spielt eine entscheidende rolle', 'es sei darauf hingewiesen'],
};

const sentences = (p: string) => p.split(/(?<=[.!?])\s+/).map((s) => s.trim()).filter(Boolean);
const clamp01 = (x: number) => Math.max(0, Math.min(1, x));

export function paragraphSignals(paragraph: string, locale: OutputLocale) {
  const ss = sentences(paragraph);
  const lens = ss.map((s) => s.split(/\s+/).length);
  const mean = lens.reduce((a, b) => a + b, 0) / Math.max(1, lens.length);
  const sd = Math.sqrt(lens.reduce((n, l) => n + (l - mean) ** 2, 0) / Math.max(1, lens.length));
  const cv = mean ? sd / mean : 1;
  // Baja variación de longitud (poca "burstiness") = más propio de texto generado.
  const burstiness = ss.length < 3 ? 0.3 : clamp01(1 - cv / 0.6);
  const low = paragraph.toLowerCase();
  const templates = clamp01(TEMPLATE_PHRASES[locale].filter((t) => low.includes(t)).length / 2);
  const openings = ss.map((s) => s.toLowerCase().split(/\s+/).slice(0, 2).join(' '));
  const repeated = openings.length - new Set(openings).size;
  const repetition = ss.length < 3 ? 0 : clamp01(repeated / (ss.length - 1));
  return { burstiness, templates, repetition };
}

const LlmSchema = z.object({ paragraphs: z.array(z.object({ index: z.number().int().nonnegative(), probability: z.number().min(0).max(1) })) });

export async function detectAiText(o: { text: string; locale: OutputLocale; c2pa: { images: number; withCredentials: number } | null; ctx?: StageCtx }): Promise<StageResult<AiAuthorship>> {
  const paras = o.text.split(/\n{2,}/).map((p) => p.trim()).filter(Boolean);
  const sig = paras.map((p) => paragraphSignals(p, o.locale));
  const c2paMissing = o.c2pa && o.c2pa.images > 0 ? 1 - o.c2pa.withCredentials / o.c2pa.images : null;
  let probs = sig.map((s) => clamp01(0.4 * s.burstiness + 0.35 * s.templates + 0.25 * s.repetition));
  let usage = ZERO_USAGE;
  const avg = (k: keyof (typeof sig)[number]) => sig.reduce((n, s) => n + s[k], 0) / Math.max(1, sig.length);
  const signals: AiAuthorship['signals'] = [
    { key: 'burstiness', value: avg('burstiness'), strength: avg('burstiness') },
    { key: 'templates', value: avg('templates'), strength: avg('templates') },
    { key: 'repetition', value: avg('repetition'), strength: avg('repetition') },
  ];
  if (c2paMissing !== null) signals.push({ key: 'c2pa', value: c2paMissing, strength: 0.3 * c2paMissing });
  if (o.ctx) {
    const r = await generateStructured({
      model: o.ctx.model,
      schema: LlmSchema,
      system: `Estimate for each numbered paragraph the probability (0–1) that it was machine-generated. This is a weak hint, not proof.\n${UNTRUSTED_NOTE}`,
      prompt: paras.map((p, i) => delimit(`P${i}`, p)).join('\n'),
      stage: 'aiDetect',
      temperature: 0,
      noTemperature: o.ctx.noTemperature,
      signal: o.ctx.signal,
    });
    usage = r.usage;
    const llm = new Map(r.object.paragraphs.map((p) => [p.index, p.probability]));
    probs = probs.map((p, i) => (llm.has(i) ? (p + llm.get(i)!) / 2 : p));
    const llmAvg = [...llm.values()].reduce((a, b) => a + b, 0) / Math.max(1, llm.size);
    signals.push({ key: 'llm', value: llmAvg, strength: llmAvg });
  }
  const probability = clamp01(probs.reduce((a, b) => a + b, 0) / Math.max(1, probs.length) * (c2paMissing !== null ? 0.9 + 0.1 * c2paMissing : 1));
  return { value: { probability, paragraphs: probs.map((p, i) => ({ index: i, probability: p })), signals }, usage };
}
```

```ts
import { stepCountIs, streamText, tool } from 'ai';
import { z } from 'zod';
import { delimit, UNTRUSTED_NOTE } from '../llm/delimit';
import { languageInstruction } from '../llm/language';
import type { Usage } from '../llm/structured';
import type { CoverageService, ExtractFn, SourceFetcher } from '../run/ports';
import type { AgentCitation, AgentEvent, AgentMode, MediaItem } from '../schemas/agent';
import type { ArticleInput } from '../schemas/article';
import type { Coverage } from '../schemas/coverage';
import type { Verdict } from '../schemas/verdicts';
import { VisualizationSchema } from '../schemas/visualization';
import type { StageCtx } from './ctx';
import { validateVisualizations } from './synthesis';
import type { RetrievedSource } from './verify';

export interface AgentContext {
  article: ArticleInput;
  coverages: Coverage[];
  sources: RetrievedSource[];
  verdicts: Verdict[];
  fragment?: string;
  partyIds: Set<string>;
  primaryDomains: string[];
}

const MODE: Record<AgentMode, string> = {
  ask: 'Answer the question about the article.',
  verify: 'Check whether the selected fragment or claim is accurate, using the retrieved sources.',
  explain: 'Explain the context and background needed to understand the fragment.',
};

export function cleanCitations(text: string, sources: RetrievedSource[]): { text: string; citations: AgentCitation[] } {
  const citations = new Map<number, AgentCitation>();
  const cleaned = text
    .replace(/\s*\[(\d+)\]/g, (m, d: string) => {
      const n = Number(d);
      const s = sources[n - 1];
      if (!s) return '';
      citations.set(n, { n, sourceId: s.id, title: s.title, url: s.url });
      return m;
    })
    .replace(/\s+([,.;])/g, '$1');
  return { text: cleaned, citations: [...citations.values()].sort((a, b) => a.n - b.n) };
}

const inDomains = (u: string, ds: string[]) => {
  try {
    const h = new URL(u).hostname;
    return ds.some((d) => h === d || h.endsWith(`.${d}`));
  } catch {
    return false;
  }
};

export async function runAgent(o: {
  ctx: StageCtx;
  context: AgentContext;
  mode: AgentMode;
  question: string;
  history?: { role: 'user' | 'assistant'; content: string }[];
  coverage: CoverageService;
  fetcher: SourceFetcher;
  extract: ExtractFn;
  onEvent: (e: AgentEvent) => void;
}): Promise<{ text: string; citations: AgentCitation[]; usage: Usage }> {
  const c = o.context;
  const sources = c.sources;
  const sourceList = () => sources.map((s, i) => `[${i + 1}] ${s.title} — ${s.url}`).join('\n');
  const coverageUrls = () => new Set(c.coverages.map((x) => x.url));

  const tools = {
    searchCoverage: tool({
      description: 'Search other outlets covering a topic in the local news index.',
      inputSchema: z.object({ query: z.string() }),
      execute: async ({ query }) => {
        o.onEvent({ type: 'step', tool: 'searchCoverage' });
        const found = await o.coverage.search(query);
        c.coverages.push(...found.filter((f) => !coverageUrls().has(f.url)));
        return found.slice(0, 8).map((f) => ({ outlet: f.outlet, title: f.title, url: f.url, bucket: f.bucket }));
      },
    }),
    fetchSource: tool({
      description: 'Fetch a primary source (whitelisted domains) or a coverage article to read it. Returns its citation number.',
      inputSchema: z.object({ url: z.string() }),
      execute: async ({ url }) => {
        o.onEvent({ type: 'step', tool: 'fetchSource' });
        const isCoverage = coverageUrls().has(url);
        if (!isCoverage && !inDomains(url, c.primaryDomains)) return { error: 'not allowed: only primary-source domains or coverage articles' };
        const existing = sources.findIndex((s) => s.url === url);
        if (existing >= 0) return { n: existing + 1, text: sources[existing]!.text.slice(0, 4000) };
        const a = o.extract(await o.fetcher.fetch(url, isCoverage ? [url] : []), url);
        if (!a) return { error: 'could not extract text' };
        sources.push({ id: `S${sources.length + 1}`, url, title: a.title || url, kind: isCoverage ? 'coverage' : 'primary', text: a.text.slice(0, 6000), media: [] });
        return { n: sources.length, title: a.title, text: a.text.slice(0, 4000) };
      },
    }),
    getVerdicts: tool({
      description: 'Get the verdicts already computed for the article claims.',
      inputSchema: z.object({}),
      execute: async () => {
        o.onEvent({ type: 'step', tool: 'getVerdicts' });
        return c.verdicts.map((v) => ({ claimId: v.claimId, status: v.status, explanation: v.explanation }));
      },
    }),
    renderVisualization: tool({
      description: 'Draw a chart inline (bar, line, range, stacked, matrix, table, parliament, map). Data must come from cited sources (sourceIds S1…).',
      inputSchema: z.object({ viz: VisualizationSchema }),
      execute: async ({ viz }) => {
        o.onEvent({ type: 'step', tool: 'renderVisualization' });
        const [ok] = validateVisualizations([viz], new Set(sources.map((s) => s.id)), c.partyIds);
        if (!ok) return { error: 'rejected: every chart needs data from a retrieved source and valid parties/majority' };
        o.onEvent({ type: 'visualization', viz: ok });
        return { ok: true };
      },
    }),
    showMedia: tool({
      description: 'Show an image or video that appears in a retrieved source. Never generated media.',
      inputSchema: z.object({ sourceId: z.string(), url: z.string(), kind: z.enum(['image', 'video']), caption: z.string() }),
      execute: async (m) => {
        o.onEvent({ type: 'step', tool: 'showMedia' });
        const src = sources.find((s) => s.id === m.sourceId);
        if (!src || !src.media.some((x) => x.url === m.url && x.kind === m.kind)) return { error: 'rejected: media must belong to the cited source' };
        const item: MediaItem = { kind: m.kind, url: m.url, sourceId: m.sourceId, caption: m.caption };
        o.onEvent({ type: 'media', media: item });
        return { ok: true };
      },
    }),
  };

  const system = [
    'You are the newpaper agent. Ground every factual statement in the numbered sources and cite them as [n]. If the sources do not settle something, say so.',
    MODE[o.mode],
    `Sources:\n${sourceList()}`,
    UNTRUSTED_NOTE,
    languageInstruction(o.ctx.locale),
  ].join('\n');
  const prompt = [
    delimit('ARTICLE', c.article.text.slice(0, 12000)),
    c.fragment ? delimit('FRAGMENT', c.fragment) : '',
    `Question: ${o.question}`,
  ].filter(Boolean).join('\n');

  const result = streamText({
    model: o.ctx.model,
    system,
    messages: [...(o.history ?? []), { role: 'user', content: prompt }],
    tools,
    stopWhen: stepCountIs(6),
    temperature: o.ctx.noTemperature ? undefined : o.ctx.temperature,
    abortSignal: o.ctx.signal,
  });
  let raw = '';
  try {
    for await (const delta of result.textStream) {
      raw += delta;
      o.onEvent({ type: 'text', delta });
    }
  } catch (e) {
    o.onEvent({ type: 'error', message: e instanceof Error ? e.message : String(e) });
    throw e;
  }
  const usage = await result.totalUsage;
  const final = cleanCitations(raw, sources);
  o.onEvent({ type: 'done', text: final.text, citations: final.citations });
  return { ...final, usage: { inputTokens: usage.inputTokens ?? 0, outputTokens: usage.outputTokens ?? 0 } };
}
```

```ts
export interface StageEvent { stage: StageId; status: 'running' | 'done' | 'cached' | 'failed' | 'skipped'; error?: string; usedFallback?: boolean }
export interface RunOpts { signal?: AbortSignal; onStage?: (e: StageEvent) => void }
export interface AnalysisResult {
  url: string;
  hash: string;
  quick: boolean;
  claims: ClaimsOutput | null;
  coverage: CoverageResult | null;
  verdicts: Verdict[] | null;
  sources: RetrievedSource[];
  score: Score | null;
  synthesis: Synthesis | null;
  aiAuthorship: AiAuthorship | null;
  uncovered: boolean;
  failed: StageId[];

}

const host = (u: string) => {
  try {
    return new URL(u).hostname.replace(/^www\./, '');
  } catch {
    return '';
  }
};

export function createPipeline(deps: PipelineDeps) {
  const ctxOf = (a: Assignment, signal?: AbortSignal): StageCtx => {
    const m = deps.models.get(a);
    return { model: m.model, noTemperature: m.noTemperature, temperature: a.temperature, locale: deps.locale(), signal };
  };

  /** Ejecuta una etapa LLM con fallback, contabiliza el consumo y devuelve el valor con el modelo usado. */
  async function runLlm<T>(a: Assignment, signal: AbortSignal | undefined, fn: (ctx: StageCtx) => Promise<StageResult<T>>) {
    const call = async (ref: { provider: string; model: string; temperature?: number }) => {
      const r = await fn(ctxOf(ref, signal));
      const cost = costOf(deps.registry.model(ref.provider, ref.model), r.usage.inputTokens, r.usage.outputTokens) ?? 0;
      await deps.usage.record(ref.provider, ref.model, r.usage as Usage, cost);
      return { value: r.value, model: `${ref.provider}/${ref.model}`, costUsd: cost };
    };
    const fb = a.fallback;
    const r = await runWithFallback(() => call(a), fb ? () => call(fb) : undefined);
    return { ...r.value, usedFallback: r.usedFallback };
  }

  async function prepare(article: ArticleInput) {
    const { spentUsd, limitUsd } = await deps.budget();
    const budget = applyBudget(await deps.assignments(), spentUsd, limitUsd, deps.registry);
    return { assignments: budget.assignments as Assignments, capped: budget.capped, hash: await textHash(article.url, article.text) };
  }

  function stageRunner(article: ArticleInput, hash: string, opts: RunOpts, failed: StageId[]) {
    const emit = (e: StageEvent) => opts.onStage?.(e);
    return async function stage<T>(id: StageId, a: Assignment | undefined, fn: (ctx: StageCtx) => Promise<StageResult<T>>, cacheIt = true): Promise<T | null> {
      if (!a) {
        emit({ stage: id, status: 'skipped' });
        return null;
      }
      emit({ stage: id, status: 'running' });
      try {
        let usedFallback = false;
        const compute = async () => {
          const r = await runLlm(a, opts.signal, fn);
          usedFallback = r.usedFallback;
          return r;
        };
        const r = cacheIt ? await cachedStage(deps.cache, article.url, hash, id, compute) : { value: (await compute()).value, fromCache: false };
        emit(r.fromCache ? { stage: id, status: 'cached' } : { stage: id, status: 'done', ...(usedFallback ? { usedFallback } : {}) });
        return r.value as T;
      } catch (e) {
        failed.push(id);
        emit({ stage: id, status: 'failed', error: e instanceof Error ? e.message : String(e) });
        return null;
      }
    };
  }

  async function runQuickAnalysis(article: ArticleInput, opts: RunOpts = {}): Promise<AnalysisResult> {
    const { assignments, capped, hash } = await prepare(article);
    const failed: StageId[] = [];
    const stage = stageRunner(article, hash, opts, failed);
    const a = assignments.quickScore ?? assignments.claims;
    const r = await stage('quickScore', a, async (ctx) => {
      const c = await detectClaims(ctx, article, { quick: true });
      const s = await quickScore({ ctx, article, lexicon: deps.lexicon, loadedPhrases: c.value.loadedPhrases.length });
      return { value: { loadedPhrases: c.value.loadedPhrases, score: s.value }, usage: { inputTokens: c.usage.inputTokens + s.usage.inputTokens, outputTokens: c.usage.outputTokens + s.usage.outputTokens } };
    });
    return {
      url: article.url, hash, quick: true,
      claims: r ? { claims: [], loadedPhrases: r.loadedPhrases } : null,
      coverage: null, verdicts: null, sources: [], score: r?.score ?? null, synthesis: null, aiAuthorship: null,
      uncovered: false, failed, capped,
    };
  }

  async function runFullAnalysis(article: ArticleInput, opts: RunOpts = {}): Promise<AnalysisResult> {
    const { assignments: as, capped, hash } = await prepare(article);
    const failed: StageId[] = [];
    const stage = stageRunner(article, hash, opts, failed);
    const locale = deps.locale();

    const claims = await stage('claims', as.claims, (ctx) => detectClaims(ctx, article, { quick: false }));
    const coverage = await findCoverage(deps.coverage, article).catch(() => null);
    const coverages = coverage?.coverages ?? [];
    let sources: RetrievedSource[] = [];

    const verdicts = await stage<Verdict[]>('verify', as.verify, async (ctx) => {
      const got = await retrieveSources({ ctx, claims: claims?.claims ?? [], coverages, primaryDomains: await deps.primaryDomains(), fetcher: deps.sources, extract: deps.extract });
      sources = got.value;
      const v = await verifyClaims(ctx, article, claims?.claims ?? [], sources);
      return { value: v.value.verdicts, usage: { inputTokens: got.usage.inputTokens + v.usage.inputTokens, outputTokens: got.usage.outputTokens + v.usage.outputTokens } };
    });
    if (!sources.length && verdicts) {
      // Resultado de la caché: se reconstruye la lista de fuentes citadas (sin texto).
      const seen = new Map<string, RetrievedSource>();
      for (const v of verdicts) for (const s of v.sources) seen.set(s.id, { ...s, text: '', media: [] });
      sources = [...seen.values()].sort((a, b) => Number(a.id.slice(1)) - Number(b.id.slice(1)));
    }

    const coverageTexts = new Map(sources.filter((s) => s.kind === 'coverage' && s.text).map((s) => [s.url, s.text]));
    const score = await stage('score', as.score, async (ctx) => {
      const b = as.judgeB;
      return scoreArticle({
        ctx,
        ctxB: b ? { ...ctxOf(b, opts.signal), label: `${b.provider}/${b.model}` } : undefined,
        article,
        coverages,
        coverageTexts,
        outletNames: [article.siteName ?? '', ...coverages.map((c) => c.outlet)].filter(Boolean),
        domains: [host(article.url), ...coverages.map((c) => host(c.url))].filter(Boolean),
        lexicon: deps.lexicon,
        loadedPhrases: claims?.loadedPhrases.length ?? 0,
        weights: await deps.framingWeights(),
      });
    });

    const partyIds = new Set(await deps.partyIds());
    const synthesis = await stage('synthesis', as.synthesis, (ctx) =>
      synthesize({ ctx, article, claims: claims?.claims ?? [], verdicts: verdicts ?? [], sources, coverages, score, partyIds }),
    );

    // El detector funciona sin modelo (señales heurísticas); el juicio LLM es opcional.
    let aiAuthorship: AiAuthorship | null = null;
    if (as.aiDetect) aiAuthorship = await stage('aiDetect', as.aiDetect, (ctx) => detectAiText({ text: article.text, locale, c2pa: null, ctx }));
    else aiAuthorship = (await detectAiText({ text: article.text, locale, c2pa: null })).value;

    const primaryCount = sources.filter((s) => s.kind === 'primary').length;
    const uncovered = coverage ? isUncovered(coverage, primaryCount) : false;
    await deps.onAnalyzed?.(article.url).catch(() => {});
    return { url: article.url, hash, quick: false, claims, coverage, verdicts, sources, score, synthesis, aiAuthorship, uncovered, failed, capped };
  }

  async function askAgent(o: {
    article: ArticleInput;
    previous: AnalysisResult | null;
    mode: AgentMode;
    question: string;
    fragment?: string;
    history?: { role: 'user' | 'assistant'; content: string }[];
    onEvent: (e: AgentEvent) => void;
    signal?: AbortSignal;
  }) {
    const a = (await deps.assignments()).agent;
    if (!a) throw new Error('no model assigned to the agent');
    const r = await runLlm(a, o.signal, async (ctx) => {
      const out = await runAgent({
        ctx,
        context: {
          article: o.article,
          coverages: [...(o.previous?.coverage?.coverages ?? [])],
          sources: [...(o.previous?.sources ?? [])],
          verdicts: o.previous?.verdicts ?? [],
          fragment: o.fragment,
          partyIds: new Set(await deps.partyIds()),
          primaryDomains: await deps.primaryDomains(),
        },
        mode: o.mode,
        question: o.question,
        history: o.history,
        coverage: deps.coverage,
        fetcher: deps.sources,
        extract: deps.extract,
        onEvent: o.onEvent,
      });
      return { value: { text: out.text, citations: out.citations }, usage: out.usage };
    });
    return r.value;
  }

  async function investigateUncovered(o: { article: ArticleInput; previous: AnalysisResult | null; acknowledged: true; signal?: AbortSignal }): Promise<UnverifiedReport> {
    const a = (await deps.assignments()).investigate;
    if (!a) throw new Error('no model assigned to the investigation');
    const r = await runLlm(a, o.signal, (ctx) => investigate({ ctx, article: o.article, sources: o.previous?.sources ?? [], acknowledged: o.acknowledged }));
    return r.value;
  }

  return {
    runQuickAnalysis,
    runFullAnalysis,
    askAgent,
    investigateUncovered,
    testConnection: (ref: { provider: string; model: string }) => testConnection(deps.models.get(ref).model),
  };
}

export type Pipeline = ReturnType<typeof createPipeline>;
```

```ts
async function build(): Promise<Pipeline> {
  const registry = await getRegistry();
  const contentLocale = asLocale(await commands.settingsGet<string>('content.locale'));
  const uiLocale = asLocale(await commands.settingsGet<string>('general.locale'));
  const custom = (await commands.settingsGet<CustomEndpoint[]>('ai.customEndpoints')) ?? [];
  const primary = await readJson<Record<string, { dominio: string }[]>>('primary-sources.json', {});
  const parties = await readJson<{ parties?: { id: string }[] }>(`parties-${contentLocale}.json`, {});
  const weights = await readJson<FramingWeights>('framing-weights.json', DEFAULT_WEIGHTS);
  return createPipeline({
    registry,
    models: {
      get(ref) {
        const p = registry.get(ref.provider);
        if (!p) throw new Error(`unknown provider ${ref.provider}`);
        const base = custom.find((c) => c.id === ref.provider)?.baseUrl;
        const m = registry.model(ref.provider, ref.model);
        return { model: createModel(p, ref.model, makeProxyFetch(ref.provider, tauriInvoker), base), noTemperature: m?.noTemperature ?? false };
      },
    },
    async assignments() {
      const saved = (await commands.settingsGet<Assignments>('ai.assignments')) ?? {};
      if (Object.keys(saved).length) return saved;
      const connected = (await commands.settingsGet<string[]>('ai.connected')) ?? [];
      const preset = ((await commands.settingsGet<PresetId>('ai.preset')) ?? 'balanced') as PresetId;
      const probe = await commands.aiLocalProbe().catch(() => ({ ollama: null, lmstudio: null }));
      const local: Record<string, string[]> = {};
      if (probe.ollama?.length) local.ollama = probe.ollama;
      if (probe.lmstudio?.length) local.lmstudio = probe.lmstudio;
      return autoAssign(registry, [...connected, ...Object.keys(local)], preset, local);
    },
    async budget() {
      const limit = await commands.settingsGet<number>('ai.monthlyLimitUsd');
      return { spentUsd: (await commands.usageMonth()).cost, limitUsd: typeof limit === 'number' ? limit : null };
    },
    usage: tauriUsage,
    cache: tauriCache,
    coverage: tauriCoverage,
    lexicon: tauriLexicon,
    sources: tauriSources,
    extract,
    primaryDomains: async () => (primary[contentLocale] ?? []).map((p) => p.dominio),
    partyIds: async () => (parties.parties ?? []).map((p) => p.id),
    framingWeights: async () => weights,
    // El idioma de salida es el de la interfaz (§14): el usuario lee los análisis en su idioma.
    locale: () => uiLocale,
    onAnalyzed: async (url) => void (await commands.historyMarkAnalyzed(url)),
  });
}

export function getPipeline(): Promise<Pipeline> {
  pipelineP ??= build();
  return pipelineP;
}

/** Llamar tras cambiar cualquier ajuste `ai.*`, `content.locale` o `general.locale`. */
export function resetPipeline(): void {
  pipelineP = null;
}

export function useAiSettings() {
  const [assignments, setAssignments] = useSetting<Assignments>('ai.assignments', {});
  const [preset, setPreset] = useSetting<PresetId>('ai.preset', 'balanced');
  const [monthlyLimitUsd, setMonthlyLimitUsd] = useSetting<number | null>('ai.monthlyLimitUsd', null);
  const [connected, setConnected] = useSetting<string[]>('ai.connected', []);
  const [quickOnOpen, setQuickOnOpen] = useSetting<boolean>('ai.quickOnOpen', true);
  const [autoFull, setAutoFull] = useSetting<boolean>('ai.autoFull', false);
  const [detector, setDetector] = useSetting<boolean>('ai.detector', true);
  const wrap = <T,>(set: (v: T) => Promise<void>) => async (v: T) => {
    await set(v);
    resetPipeline();
  };
  return {
    assignments, setAssignments: wrap(setAssignments),
    preset, setPreset: wrap(setPreset),
    monthlyLimitUsd, setMonthlyLimitUsd: wrap(setMonthlyLimitUsd),
    connected, setConnected: wrap(setConnected),
    quickOnOpen, setQuickOnOpen,
    autoFull, setAutoFull,
    detector, setDetector,
  };
}
```
