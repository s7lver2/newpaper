# newpaper · Subproyecto 8 — Móvil (Android primero, después iOS) · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** newpaper en el móvil con Tauri 2: lector y **compartir para analizar** (intent de Android, extensión de compartir de iOS), pantallas M0–M10 de la pizarra, bloqueo por intercepción de peticiones (Android) y listas de contenido de WebKit (iOS), Tor con Arti y proxy en la webview, emparejamiento con el PC por QR (subproyecto 7) e IA local a través del Ollama del PC (red local o Tailscale).

**Architecture:** Una app nueva `apps/mobile` (React 19, navegación de móvil: Hoy / Leyendo / Agente / Ajustes) que reutiliza `@newpaper/pipeline`, `@newpaper/ui-kit`, `@newpaper/i18n` y `@newpaper/extract`, empaquetada por el **mismo** crate `np-app` con `tauri.android.conf.json` y `tauri.ios.conf.json`. Lo exclusivo de escritorio queda tras `#[cfg(desktop)]` (WebView2, pestañas, actualizador, instalador). Lo nativo vive en un plugin local `tauri-plugin-np-mobile` (Kotlin y Swift): intent de compartir, almacén seguro, webview "original" con intercepción y proxy. La lógica pura nueva va al crate `np-mobile-core`, que se prueba en el PC.

**Tech Stack:** Tauri 2.12 (móvil), `tauri-plugin-barcode-scanner` 2.5.1, `tauri-plugin-notification` 2.5.1, `jni` 0.21.1, Kotlin + `androidx.webkit` 1.12 (`ProxyController`), Android Keystore (`EncryptedSharedPreferences`, `androidx.security:security-crypto` 1.1.0), Swift (Keychain, `WKContentRuleListStore`, `ProxyConfiguration` de iOS 17), `arti-client` 0.47 con rustls, `adblock` 0.13.3 (`content-blocking` para iOS), React 19, Vite 8, Vitest 5.

## Decisiones tomadas

1. **App separada** `apps/mobile` (no rutas responsivas en `apps/ui`): navegación inferior, hojas, pulsación larga, sin pestañas ni multi-webview. Las piezas puras que ya existen en `apps/ui` y hacen falta aquí (`renderCitations`/`applyAgentEvent`, `groupByDay`, `applyRewrites`, el minimax del tres en raya) **se mueven** a `@newpaper/ui-kit/logic` (Tarea 4) y `apps/ui` pasa a importarlas de ahí.
2. **Mismo crate `np-app`** para escritorio y móvil, con `#[cfg(desktop)]` / `#[cfg(mobile)]` (los emite `tauri-build`). `np-shell` se parte: `ShellExtensions` y la lógica pura compilan en todas partes; `TabManager` y el código WebView2 quedan tras `cfg(windows)`.
3. **Lectura**: vía rápida = Rust descarga el HTML con el cliente `Content` (Tor/directo y kill switch del subproyecto 2) y la UI extrae con Readability + DOMPurify. Vía de respaldo = "Ver original" abre la webview nativa del plugin (intercepción de anuncios y proxy Tor) y, al pulsar "Analizar", devuelve el `outerHTML` a la UI.
4. **JNI**: se fija `jni` 0.21.1 (API conocida: `JNIEnv`, `JClass`, `JString`); la 0.22 cambió su API y no se ha verificado. El adblock de Android llama a Rust con `NpNative.shouldBlock(url, sourceUrl, type)`.
5. **Kill switch en móvil**: el proxy de la webview lo decide solo Rust (`np_mobile_core::proxy::decide`) a partir del `NetStatus`; con Tor pedido y no listo se pone un proxy a un puerto cerrado (`127.0.0.1:9`), así que nada sale en directo. JS nunca cambia el proxy.
6. **Claves en el móvil**: `MobileSecrets` implementa `SecretStore` sobre el plugin (Android Keystore vía `EncryptedSharedPreferences`; iOS Keychain). `keyring` solo en escritorio.
7. **Emparejamiento**: el móvil escanea el QR del PC (`barcode-scanner`) y llama a `sync_pair_with` (subproyecto 7). El móvil nunca escucha conexiones: sincroniza como cliente al abrir, cada 5 minutos con la app abierta y con "Sincronizar ahora".
8. **Ollama del PC**: tras emparejar se ofrece "Usar el Ollama de <PC>": se prueba `http://<IP del PC>:11434/api/tags` y, si responde, se registra un endpoint propio con id `ollama` (base `http://<IP>:11434/v1`). Solo se aceptan direcciones de LAN privada, Tailscale (100.64.0.0/10 o `*.ts.net`) o loopback (`np_mobile_core::ollama::classify`). Requiere `OLLAMA_HOST=0.0.0.0` en el PC (la pantalla lo explica) y Ollama no tiene autenticación: se avisa de exponerlo solo en redes de confianza. Un relé cifrado por el canal de sincronización queda para una versión posterior.
9. **Actualizaciones**: la app por tienda o APK firmado; el contenido con el mismo manifiesto firmado del subproyecto 6 (`np-update::content` compila en móvil).
10. **iOS**: misma base; la extensión de compartir es un target aparte de Xcode que escribe la URL en el App Group `group.app.newpaper` y abre `newpaper://share`. Los pasos de Xcode que no se pueden automatizar se describen en la Tarea 6.
11. **`minSdk` 24** (Arti necesita Android 7.0+); proxy de la webview en iOS requiere iOS 17.

pub fn run() {
    let builder = tauri::Builder::default();
    #[cfg(desktop)]
    let builder = builder
        .plugin(tauri_plugin_single_instance::init(|app, argv, _cwd| crate::system::on_second_instance(app, argv)))
        .plugin(tauri_plugin_updater::Builder::new().build())
        .plugin(tauri_plugin_autostart::init(tauri_plugin_autostart::MacosLauncher::LaunchAgent, None))
        .register_asynchronous_uri_scheme_protocol("npimg", npimg::handle);
    #[cfg(mobile)]
    let builder = builder.plugin(tauri_plugin_barcode_scanner::init()).plugin(tauri_plugin_np_mobile::init());
    builder
        .plugin(tauri_plugin_process::init())
        .plugin(tauri_plugin_dialog::init())
        .setup(setup::setup)
        .invoke_handler(handlers!())
        .build(tauri::generate_context!())
        .expect("error while building newpaper")
        .run(|_app, _event| {
            #[cfg(desktop)]

                crate::system::updater::on_exit(_app);
            }
        });
}

const TRACKING: &[&str] = &["fbclid", "gclid", "mc_cid", "mc_eid", "igshid"];

pub fn extract_url(text: &str) -> Option<String> {
    let start = text.find("https://").or_else(|| text.find("http://"))?;
    let rest = &text[start..];
    let end = rest.find(|c: char| c.is_whitespace() || c == '"' || c == '<' || c == '>').unwrap_or(rest.len());
    let raw = rest[..end].trim_end_matches(['.', ',', ';', ':', ')', ']', '!', '?', '»']);
    let mut url = url::Url::parse(raw).ok()?;
    if !matches!(url.scheme(), "http" | "https") {
        return None;

    let kept: Vec<(String, String)> = url.query_pairs().filter(|(k, _)| !k.starts_with("utm_") && !TRACKING.contains(&k.as_ref())).map(|(k, v)| (k.into_owned(), v.into_owned())).collect();
    if kept.is_empty() {
        url.set_query(None);
    } else {
        url.query_pairs_mut().clear().extend_pairs(kept);
    }
    url.set_fragment(None);

use std::net::{IpAddr, Ipv4Addr};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Endpoint {
    pub base: String,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum OllamaRejection {
    NotHttp,
    PublicAddress,
    Unparseable,
}

fn private_v4(ip: Ipv4Addr) -> bool {
    let o = ip.octets();
    ip.is_loopback() || ip.is_private() || (o[0] == 100 && (o[1] & 0xC0) == 64)
}

pub fn classify(raw: &str) -> Result<Endpoint, OllamaRejection> {
    let url = url::Url::parse(raw.trim()).map_err(|_| OllamaRejection::Unparseable)?;
    if !matches!(url.scheme(), "http" | "https") {
        return Err(OllamaRejection::NotHttp);
    }
    let host = url.host_str().ok_or(OllamaRejection::Unparseable)?.to_ascii_lowercase();
    let ok = match host.parse::<IpAddr>() {
        Ok(IpAddr::V4(v4)) => private_v4(v4),
        Ok(IpAddr::V6(v6)) => v6.is_loopback(),
        Err(_) => host == "localhost" || host.ends_with(".ts.net") || url.scheme() == "https",
    };
    if !ok {
        return Err(OllamaRejection::PublicAddress);
    }
    let base = format!("{}://{}{}", url.scheme(), url.host_str().unwrap_or_default(), url.port().map(|p| format!(":{p}")).unwrap_or_default());
    Ok(Endpoint { base })
}

//! Descarga del artículo por el cliente de contenidos (respeta Tor y el kill switch).
use thiserror::Error;

pub const MAX_BYTES: usize = 5 * 1024 * 1024;

#[derive(Debug, Error, PartialEq, Eq, serde::Serialize)]
#[serde(tag = "kind", content = "detail", rename_all = "camelCase")]
pub enum FetchError {
    #[error("network")]
    Network,
    #[error("status {0}")]
    Status(u16),
    #[error("too large")]
    TooLarge,
    #[error("not html")]
    NotHtml,
    #[error("blocked by kill switch")]
    Blocked,
}

pub async fn fetch_page(client: &reqwest::Client, url: &str) -> Result<String, FetchError> {
    let r = client.get(url).send().await.map_err(|e| if e.is_connect() { FetchError::Blocked } else { FetchError::Network })?;
    if !r.status().is_success() {
        return Err(FetchError::Status(r.status().as_u16()));
    }
    let html = r.headers().get(reqwest::header::CONTENT_TYPE).and_then(|v| v.to_str().ok()).map_or(true, |ct| ct.contains("html"));
    if !html {
        return Err(FetchError::NotHtml);
    }
    if r.content_length().is_some_and(|n| n as usize > MAX_BYTES) {
        return Err(FetchError::TooLarge);
    }
    let bytes = r.bytes().await.map_err(|_| FetchError::Network)?;
    if bytes.len() > MAX_BYTES {
        return Err(FetchError::TooLarge);
    }
    Ok(String::from_utf8_lossy(&bytes).into_owned())
}
```

                return if (NpNative.shouldBlock(request.url.toString(), source, type)) {

                val html = org.json.JSONArray("[$json]").getString(0)
                onHtml(web.url ?: url, html)
            }
        } })
        bar.addView(Button(activity).apply { text = closeLabel; minHeight = 132; setOnClickListener { close() } })

    }

    }

@InvokeArg class KeyArgs { lateinit var key: String; var value: String? = null }
@InvokeArg class Labels { lateinit var close: String; lateinit var analyze: String }
@InvokeArg class OpenArgs { lateinit var url: String; lateinit var labels: Labels }
@InvokeArg class ProxyArgs { lateinit var kind: String; var port: Int = 0 }
@InvokeArg class MulticastArgs { var on: Boolean = false }

@TauriPlugin
class NpMobilePlugin(private val activity: Activity) : Plugin(activity) {
    private val store by lazy { SecureStore(activity) }
    private val original by lazy { OriginalWebView(activity) { url, html -> trigger("original-html", JSObject().put("url", url).put("html", html)) } }
    private var pending: String? = null
    private var lock: WifiManager.MulticastLock? = null

    override fun load(webView: android.webkit.WebView) {
        pending = textOf(activity.intent)
    }

    override fun onNewIntent(intent: Intent) {
        textOf(intent)?.let { pending = it; trigger("share", JSObject().put("text", it)) }
    }

    private fun textOf(intent: Intent?): String? = when (intent?.action) {
        Intent.ACTION_SEND -> intent.getStringExtra(Intent.EXTRA_TEXT)
        Intent.ACTION_VIEW -> intent.dataString
        else -> null
    }

    @Command fun pendingShare(invoke: Invoke) {
        val v = pending; pending = null
        invoke.resolve(JSObject().put("value", v))
    }
    @Command fun secureGet(invoke: Invoke) {
        val a = invoke.parseArgs(KeyArgs::class.java)
        invoke.resolve(JSObject().put("value", store.get(a.key)))
    }
    @Command fun secureSet(invoke: Invoke) {
        val a = invoke.parseArgs(KeyArgs::class.java)
        store.set(a.key, a.value ?: ""); invoke.resolve()
    }
    @Command fun secureDelete(invoke: Invoke) {
        store.delete(invoke.parseArgs(KeyArgs::class.java).key); invoke.resolve()
    }
    @Command fun originalOpen(invoke: Invoke) {
        val a = invoke.parseArgs(OpenArgs::class.java)
        activity.runOnUiThread { original.open(a.url, a.labels.close, a.labels.analyze); invoke.resolve() }
    }
    @Command fun originalClose(invoke: Invoke) {
        activity.runOnUiThread { original.close(); invoke.resolve() }
    }
    /** Solo Rust la llama (decisión 5). `Block` apunta a un puerto cerrado: nada sale en directo. */
    @Command fun setProxy(invoke: Invoke) {
        val a = invoke.parseArgs(ProxyArgs::class.java)
        if (!WebViewFeature.isFeatureSupported(WebViewFeature.PROXY_OVERRIDE)) { invoke.reject("proxy override not supported"); return }
        val ctl = ProxyController.getInstance()
        val done = Runnable { invoke.resolve() }
        when (a.kind) {
            "direct" -> ctl.clearProxyOverride({ it.run() }, done)
            "socks" -> ctl.setProxyOverride(ProxyConfig.Builder().addProxyRule("socks5://127.0.0.1:${a.port}").build(), { it.run() }, done)
            else -> ctl.setProxyOverride(ProxyConfig.Builder().addProxyRule("socks5://127.0.0.1:9").build(), { it.run() }, done)
        }
    }
    @Command fun multicast(invoke: Invoke) {
        val on = invoke.parseArgs(MulticastArgs::class.java).on
        val wifi = activity.applicationContext.getSystemService(Context.WIFI_SERVICE) as WifiManager
        if (on && lock == null) lock = wifi.createMulticastLock("newpaper-mdns").apply { setReferenceCounted(false); acquire() }
        if (!on) { lock?.release(); lock = null }
        invoke.resolve()
    }
}

import Network
import Security
import SwiftRS
import Tauri
import UIKit
import WebKit

struct KeyArgs: Decodable { let key: String; let value: String? }
struct Labels: Decodable { let close: String; let analyze: String }
struct OpenArgs: Decodable { let url: String; let labels: Labels }
struct ProxyArgs: Decodable { let kind: String; let port: Int? }

final class NpMobilePlugin: Plugin {
  private let group = UserDefaults(suiteName: "group.app.newpaper")
  private var original: WKWebView?
  private var proxy: ProxyArgs = ProxyArgs(kind: "direct", port: nil)

  @objc public func pendingShare(_ invoke: Invoke) {
    let v = group?.string(forKey: "pendingShare")
    group?.removeObject(forKey: "pendingShare")
    invoke.resolve(["value": v as Any])
  }

  private func query(_ key: String) -> [String: Any] {
    [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: "newpaper", kSecAttrAccount as String: key]
  }
  @objc public func secureGet(_ invoke: Invoke) throws {
    let a = try invoke.parseArgs(KeyArgs.self)
    var q = query(a.key); q[kSecReturnData as String] = true
    var out: AnyObject?
    let ok = SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess
    invoke.resolve(["value": ok ? String(data: out as! Data, encoding: .utf8) as Any : NSNull()])
  }
  @objc public func secureSet(_ invoke: Invoke) throws {
    let a = try invoke.parseArgs(KeyArgs.self)
    SecItemDelete(query(a.key) as CFDictionary)
    var q = query(a.key); q[kSecValueData as String] = (a.value ?? "").data(using: .utf8)!
    q[kSecAttrAccessible as String] = kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly
    SecItemAdd(q as CFDictionary, nil)
    invoke.resolve()
  }
  @objc public func secureDelete(_ invoke: Invoke) throws {
    SecItemDelete(query(try invoke.parseArgs(KeyArgs.self).key) as CFDictionary)
    invoke.resolve()
  }

  @objc public func setProxy(_ invoke: Invoke) throws {
    proxy = try invoke.parseArgs(ProxyArgs.self)
    invoke.resolve()
  }

  @objc public func originalOpen(_ invoke: Invoke) throws {
    let a = try invoke.parseArgs(OpenArgs.self)
    DispatchQueue.main.async {
      let cfg = WKWebViewConfiguration()
      if #available(iOS 17.0, *) {
        let store = WKWebsiteDataStore.nonPersistent()
        if self.proxy.kind != "direct" {
          let port = NWEndpoint.Port(rawValue: UInt16(self.proxy.kind == "socks" ? (self.proxy.port ?? 9) : 9))!
          store.proxyConfigurations = [ProxyConfiguration(socksv5Proxy: .hostPort(host: "127.0.0.1", port: port))]
        }
        cfg.websiteDataStore = store
      }
      WKContentRuleListStore.default().lookUpContentRuleList(forIdentifier: "newpaper-blocklist") { list, _ in
        if let list { cfg.userContentController.add(list) }
        let web = WKWebView(frame: self.manager.viewController?.view.bounds ?? .zero, configuration: cfg)
        web.autoresizingMask = [.flexibleWidth, .flexibleHeight]
        self.manager.viewController?.view.addSubview(web)
        self.original = web
        web.load(URLRequest(url: URL(string: a.url)!))
        invoke.resolve()
      }
    }
  }
  @objc public func originalClose(_ invoke: Invoke) {
    DispatchQueue.main.async { self.original?.removeFromSuperview(); self.original = nil; invoke.resolve() }
  }
  @objc public func multicast(_ invoke: Invoke) { invoke.resolve() }
}

use jni::{
    objects::{JClass, JString},
    sys::{jboolean, JNI_FALSE, JNI_TRUE},
    JNIEnv,
};
use np_adblock::service::AdblockService;

pub static ADBLOCK: OnceLock<Arc<AdblockService>> = OnceLock::new();

#[no_mangle]
pub extern "system" fn Java_app_newpaper_mobile_NpNative_shouldBlock(mut env: JNIEnv, _class: JClass, url: JString, source: JString, kind: JString) -> jboolean {
    let get = |env: &mut JNIEnv, s: &JString| env.get_string(s).map(String::from).unwrap_or_default();
    let (url, source, kind) = (get(&mut env, &url), get(&mut env, &source), get(&mut env, &kind));
    match ADBLOCK.get() {
        Some(a) if a.should_block(&url, &source, &kind) => JNI_TRUE,
        _ => JNI_FALSE,
    }
}

use std::sync::Arc;

use np_mobile_core::proxy::{decide, ProxyDecision};
use np_net::NetController;
use tauri::{AppHandle, Wry};
use tauri_plugin_np_mobile::{NpMobileExt, ProxyArg};

fn apply(app: &AppHandle<Wry>, net: &NetController) {
    let s = net.status();
    let arg = match decide(s.mode, &s.tor, s.socks_port) {
        ProxyDecision::Direct => ProxyArg::Direct,
        ProxyDecision::Socks { port } => ProxyArg::Socks { port },
        ProxyDecision::Block => ProxyArg::Block,
    };
    if let Err(e) = app.np_mobile().set_proxy(arg) {
        tracing::warn!(error = %e, "webview proxy not applied");
    }
}

/// El proxy de la webview nativa lo decide solo Rust (decisión 5).
pub fn follow(app: AppHandle<Wry>, net: Arc<NetController>) {
    apply(&app, &net);
    let mut rx = net.subscribe();
    tauri::async_runtime::spawn(async move {
        while rx.changed().await.is_ok() {
            apply(&app, &net);
        }
    });
}
```

> `NetController::subscribe()` devuelve un `tokio::sync::watch::Receiver<NetStatus>` (subproyecto 2).

import { extractFromHtml } from '@newpaper/extract';
import { autoAssign, createModel, createPipeline, DEFAULT_WEIGHTS, loadRegistry, makeProxyFetch, type Assignments, type Pipeline, type PresetId } from '@newpaper/pipeline';
import { aiInvoker, ipc } from '../ipc';

let p: Promise<Pipeline> | null = null;
const json = async <T,>(name: string, fallback: T): Promise<T> => {
  try {
    return JSON.parse(await ipc.configRead(name)) as T;
  } catch {
    return fallback;
  }
};

/** Mismos puertos que el escritorio (subproyecto 4), sobre el IPC del móvil. */
async function build(): Promise<Pipeline> {
  const registry = loadRegistry(await json('providers.json', { version: 1, providers: [] }), await json('prices.json', {}));
  const locale = ((await ipc.settingsGet<string>('general.locale')) ?? 'es') as 'es' | 'en' | 'de';
  const content = (await ipc.settingsGet<string>('content.locale')) ?? 'es';
  const custom = (await ipc.settingsGet<{ id: string; baseUrl: string; models: string[] }[]>('ai.customEndpoints')) ?? [];
  const primary = await json<Record<string, { dominio: string }[]>>('primary-sources.json', {});
  const parties = await json<{ parties?: { id: string }[] }>(`parties-${content}.json`, {});
  return createPipeline({
    registry,
    models: {
      get(ref) {
        const prov = registry.get(ref.provider);
        if (!prov) throw new Error(`unknown provider ${ref.provider}`);
        const base = custom.find((c) => c.id === ref.provider)?.baseUrl;
        return { model: createModel(prov, ref.model, makeProxyFetch(ref.provider, aiInvoker), base), noTemperature: registry.model(ref.provider, ref.model)?.noTemperature ?? false };
      },
    },
    async assignments() {
      const saved = (await ipc.settingsGet<Assignments>('ai.assignments')) ?? {};
      if (Object.keys(saved).length) return saved;
      const connected = (await ipc.settingsGet<string[]>('ai.connected')) ?? [];
      const preset = ((await ipc.settingsGet<PresetId>('ai.preset')) ?? 'balanced') as PresetId;
      const pc = custom.find((c) => c.id === 'ollama');
      return autoAssign(registry, pc ? [...connected, 'ollama'] : connected, preset, pc ? { ollama: pc.models } : {});
    },
    budget: async () => ({ spentUsd: (await ipc.usageMonth()).cost, limitUsd: (await ipc.settingsGet<number>('ai.monthlyLimitUsd')) ?? null }),
    usage: { record: (prov, model, u, cost) => ipc.usageRecord(prov, model, u.inputTokens, u.outputTokens, cost) },
    cache: {
      get: async (url, hash, stage) => (await ipc.analysisCacheGet(url, hash, stage))?.json ?? null,
      put: (url, hash, stage, j, model, cost) => ipc.analysisCachePut(url, hash, stage, j, model, cost),
    },
    coverage: {
      coverageFor: (url, title, excerpt) => ipc.coverageFor(url, title, excerpt),
      async search(q) {
        const cards = (await ipc.eventsSearch(q)).slice(0, 3);
        return (await Promise.all(cards.map((c) => ipc.eventDetail(c.eventId)))).flatMap((d) => d?.articles ?? []);
      },
    },
    lexicon: { score: (text, l) => ipc.lexiconScore(text, l) },
    sources: { fetch: (url, extra) => ipc.sourceFetch(url, extra) },
    extract: (html, url) => extractFromHtml(html, url),
    primaryDomains: async () => (primary[content] ?? []).map((x) => x.dominio),
    partyIds: async () => (parties.parties ?? []).map((x) => x.id),
    framingWeights: async () => json('framing-weights.json', DEFAULT_WEIGHTS),
    locale: () => locale,
    onAnalyzed: async (url) => void (await ipc.historyMarkAnalyzed(url)),
  });
}

export const getPipeline = () => (p ??= build());
export const resetPipeline = () => void (p = null);

import { useSyncExternalStore } from 'react';

export type RouteName = 'bienvenida' | 'hoy' | 'leer' | 'agente' | 'ajustes' | 'proveedor' | 'emparejar' | 'historial' | 'edicion' | 'sin-conexion';
export interface Route { name: RouteName; params: URLSearchParams }

function parse(): Route {
  const [path, query = ''] = location.hash.replace(/^#\/?/, '').split('?');
  const name = (path || 'hoy') as RouteName;
  return { name, params: new URLSearchParams(query) };
}

let current = parse();
const listeners = new Set<() => void>();
window.addEventListener('hashchange', () => {
  current = parse();
  listeners.forEach((l) => l());
});

export const useRoute = () => useSyncExternalStore((l) => (listeners.add(l), () => listeners.delete(l)), () => current);
export function go(name: RouteName, params: Record<string, string> = {}): void {
  const q = new URLSearchParams(params).toString();
  location.hash = `/${name}${q ? `?${q}` : ''}`;
}

import { useT } from '@newpaper/i18n/react';
import { addPluginListener } from '@tauri-apps/api/core';
import { useEffect } from 'react';
import { ipc } from './ipc';
import { go, useRoute } from './router';
import { Agent } from './screens/Agent';
import { Edition } from './screens/Edition';
import { History } from './screens/History';
import { Offline } from './screens/Offline';
import { Pair } from './screens/Pair';
import { Provider } from './screens/Provider';
import { Reading } from './screens/Reading';
import { Settings } from './screens/Settings';
import { Today } from './screens/Today';
import { Welcome } from './screens/Welcome';

async function takeShare() {
  const url = await ipc.pendingShare().catch(() => null);
  if (url) go('leer', { u: url });
}

const TABS = [
  { name: 'hoy', key: 'mobile.nav.today' },
  { name: 'leer', key: 'mobile.nav.reading' },
  { name: 'agente', key: 'mobile.nav.agent' },
  { name: 'ajustes', key: 'mobile.nav.settings' },
] as const;

export function App() {
  const t = useT();
  const route = useRoute();
  useEffect(() => {
    void ipc.settingsGet<boolean>('device.mobileWelcomeDone').then((done) => {
      if (!done) go('bienvenida');
      else void takeShare();
    });
    const onVisible = () => document.visibilityState === 'visible' && void takeShare();
    document.addEventListener('visibilitychange', onVisible);
    const share = addPluginListener('np-mobile', 'share', () => void takeShare()).catch(() => null);
    const offline = () => go('sin-conexion');
    window.addEventListener('offline', offline);
    const sync = setInterval(() => void ipc.syncNow().catch(() => {}), 5 * 60_000);
    void ipc.syncNow().catch(() => {});
    return () => {
      document.removeEventListener('visibilitychange', onVisible);
      window.removeEventListener('offline', offline);
      clearInterval(sync);
      void share.then((l) => l?.unregister());
    };
  }, []);

  const screen = (() => {
    switch (route.name) {
      case 'bienvenida':
        return <Welcome />;
      case 'leer':
        return <Reading url={route.params.get('u')} />;
      case 'agente':
        return <Agent />;
      case 'ajustes':
        return <Settings />;
      case 'proveedor':
        return <Provider />;
      case 'emparejar':
        return <Pair />;
      case 'historial':
        return <History />;
      case 'edicion':
        return <Edition />;
      case 'sin-conexion':
        return <Offline />;
      default:
        return <Today />;
    }
  })();

  return (
    <div className="m-app np-root">
      <main className="m-main">{screen}</main>
      {route.name !== 'bienvenida' ? (
        <nav className="m-tabs" aria-label={t('mobile.nav.label')}>
          {TABS.map((x) => (
            <button key={x.name} type="button" aria-current={route.name === x.name ? 'page' : undefined} onClick={() => go(x.name)}>
              {t(x.key)}
            </button>
          ))}
        </nav>
      ) : null}
    </div>
  );
}

import { extractFromHtml, type Article } from '@newpaper/extract';
import type { AnalysisResult } from '@newpaper/pipeline';
import { useSyncExternalStore } from 'react';
import { getPipeline } from './ai/pipeline';
import { ipc } from './ipc';

interface State { url: string | null; article: Article | null; quick: AnalysisResult | null; full: AnalysisResult | null; busy: 'loading' | 'quick' | 'full' | null; error: string | null }
let state: State = { url: null, article: null, quick: null, full: null, busy: null, error: null };
const ls = new Set<() => void>();
const set = (p: Partial<State>) => {
  state = { ...state, ...p };
  ls.forEach((l) => l());
};
export const useReading = () => useSyncExternalStore((l) => (ls.add(l), () => ls.delete(l)), () => state);
export const readingState = () => state;

const input = (a: Article) => ({ url: a.url, title: a.title, text: a.text, lang: a.lang, siteName: a.siteName, byline: a.byline, published: a.published });

export async function showHtml(url: string, html: string): Promise<void> {
  const article = extractFromHtml(html, url);
  if (!article) return set({ busy: null, error: 'not-article' });
  set({ url, article, quick: null, full: null, busy: null, error: null });
  void ipc.historyRecordVisit(url, article.title);
  if ((await ipc.settingsGet<boolean>('ai.quickOnOpen')) ?? true) void analyze('quick');
}

export async function loadArticle(url: string): Promise<void> {
  if (state.url === url && state.article) return;
  set({ url, article: null, quick: null, full: null, busy: 'loading', error: null });
  try {
    await showHtml(url, await ipc.fetchPage(url));
  } catch (e) {
    set({ busy: null, error: String((e as { message?: string }).message ?? e) });
  }
}

export async function analyze(kind: 'quick' | 'full'): Promise<void> {
  const a = state.article;
  if (!a) return;
  set({ busy: kind, error: null });
  try {
    const p = await getPipeline();
    const r = kind === 'quick' ? await p.runQuickAnalysis(input(a)) : await p.runFullAnalysis(input(a));
    if (state.url === a.url) set(kind === 'quick' ? { quick: r, busy: null } : { full: r, busy: null });
  } catch (e) {
    if (state.url === a.url) set({ busy: null, error: String((e as Error).message ?? e) });
  }
}

export function Pair() {
  const { t } = useI18n();

  const [peer, setPeer] = useState<PeerView | null>(null);
  const [error, setError] = useState<string | null>(null);

    setState('pairing');

      setState('probing');

          setOllama(await ipc.ollamaProbe(`http://${host}:11434`));
          break;
        } catch {
          /* este PC no comparte su Ollama en esta dirección */
        }
      }
      setState('done');

      setError(String((e as { message?: string }).message ?? e));
      setState('idle');
    }
  };
  const scanQr = async () => {
    const r = await scan({ windowed: false, formats: [Format.QRCode] });

    else setError(t('mobile.pair.notNewpaper'));

      </label>

          </div>
        ) : (
          <p className="np-hint">{t('mobile.pair.ollamaHint')}</p>
        )
      ) : null}
    </section>
  );
}
