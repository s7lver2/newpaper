## No verificado

- Tor real (solo `NP_FAKE_TOR`); la transición A1 con páginas pesadas por Tor.
- `prefers-reduced-motion` real del sistema (la UI lo envía a Rust y el CSS lo respeta; no se activó en el SO).
- Releases (`--release`): las teclas F12 y devtools se desactivan siempre salvo debug + `NP_DEVTOOLS`.
- Accesibilidad con lector de pantalla del menú contextual y de la lista de pestañas (solo roles y teclado).
